Pixel Clicker First Hour

Every screen, box, goal, Cubie page and popup a new player meets, in order, from launch to buying the first skill pack. Traced from the code on 24 Oct 2026. Click a step for its trigger and source; click an ID to copy it and quote it in chat (e.g. "reword C1.8").

Rules that apply the whole time
  • Only one box shows at a time (PixelTipQueue). Order of priority: tutorials, then perk popups, then first-time tips, then Did you know.
  • First-time tips do NOT wait for a calm moment, so the husk tip (T73) can show while Cubie is about to visit. Perk popups and tutorials do wait.
  • Cubie waits for calm: no tip box, no open window, not paused, no takeover minigame, no pet popup, then 1.5 s.
  • Vendors wait for their own calm check (no tip box or pending tips, time running, not in a menu), with one shared 180 s gap between any two visitors.
  • Goals and the guide line are hidden during the intro box. The event log fades while any window is open.
  • Cubie peeks out from behind the pause menu's Save / Load, Settings and Key bindings screens at any time.
  • With "Show first-time tips" off: no intro, no Cubie visits (the Recycler and RGB arrive quietly), no tutorials and no perk popups.

Kinds: screen, intro tip, tip, goal, Cubie page, visitor, tutorial step, popup, unlock, event-log line (announce), choice. Steps on the dashed side rail can happen at any time in that phase (their trigger says when). Dialogue IDs come from docs/DialogueMap.md, UI IDs from docs/UIMap.md.
