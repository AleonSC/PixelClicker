# Game loop

`GameLoop.html` is an interactive picture of the game loop: every station (click the cube, pure currency, husks, the shop, Cubie's bill,
skills, vendors, machines, materials, products, minigames...) and the arrows between them, coloured by status (built / partly built /
designed / open question), with a ranked list of the gaps, a resources table (sources vs sinks) and what each trust phase is missing.

The data is the `N` (stations), `E` (arrows), `GAPS`, `RES` and `PH` tables at the top of the page's script, written from
docs/GameDesign.md, docs/systems/ConnectionMap.md, PixelRules.md, the to-do and the changelog. Update those tables when a part of the loop
is built or a design decision changes, then republish the page (https://claude.ai/artifact/Reaj6qMzG21Avh69NyaHw8).
