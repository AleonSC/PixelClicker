How it works: tools/code-health/build.py reads the C# text (no Unity). Every finding is a pattern with a file and line, so it is a list of places to look, not proof: "every frame" means inside Update / LateUpdate / FixedUpdate / OnGUI only (code those methods call is not followed), and one-time setup guarded by if (x == null) is not counted. Each script starts at 100 and loses capped points per finding; the overall and category scores are weighted by lines of code. Rebuild with python3 tools/code-health/build.py (it adds a point to the trend each time the score changes).
