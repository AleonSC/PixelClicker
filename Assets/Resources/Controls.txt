// CONTROLS - shown in the pause menu under "Controls". Edit this file any time.
// Lines starting with // are notes for you and are not shown.
// A line starting with # is a heading. A line like  Key | What it does  is shown as two columns.
// Keep the right-hand part short so it stays on one line.
// {key:TimeStop}, {key:TimeSlow}, {key:Hose}, {key:EventLog}, {key:RotateLeft}, {key:RotateRight}, {key:ViewWindow} are replaced by the player's current key bindings (Settings > Key Bindings).

# Mouse
Left-click the cube | Collect a pixel
Left-click a button | Use it
Mouse to a screen edge | Slide out the docked buttons
Right-click (inventory item) | Drink a potion / start placing a device
Hold right-click (placed device) | Remove it
Hold right-click ("Active:" line) | Cancel the potion

# Keyboard
Esc | Pause menu / close the top window
{key:TimeStop} | Stop and resume time (Time Stop; uses an energy meter, you can still click the cube)
Arrow keys | Steer the snake during a Snake round (or use the on-screen arrows)
{key:ViewWindow} | Open / close the View window: pick First person (WASD, mouse, Space, Shift; click the cube to click it; right-click a cube to carry it, right-click again drops it, left-click throws it; Esc leaves), Orbital (middle mouse drag or arrow keys turn round the cube) or Top down (the normal view); Ctrl + mouse wheel zooms the camera; tick Orthographic (flat) view (not in first person); zoom slider; Auto orbit and turn / tilt buttons
{key:Feedback} | Give feedback (opens a window with a text box and screenshots you can draw on; saved to the Feedback folder). Also in Settings.
{key:TimeSlow} | Slow time and back to normal (Time Slow upgrade; shares the Time Stop meter; slowed meteor pixels can be grabbed)
{key:Hose} | Equip / put away the hose (Pixel Bank)
{key:EventLog} | Open the whole event log (a new event only shows its newest line); press it again (or right-click) to hide it. Left-click a line to reopen its tip, mouse wheel scrolls
{key:RotateLeft} or {key:RotateRight} | Turn a fan or sorter while placing it
Mouse wheel | Turn a fan or sorter while placing it
Mouse wheel while holding a pixel | Raise or lower it
Ctrl + mouse wheel | Zoom the camera (the plain wheel never moves the camera)

# Placing a Device
Left-click the floor | Place a Vacuum Device or Fan
Scroll or {key:RotateLeft} / {key:RotateRight} | Turn a Fan or the Sorter's pipe
Left-click (Sorter) | Confirm the pipe's direction
Left-click in the cone | Place the Sorter with that bend
Hold Shift | Free placement (placing snaps to a grid and to turn steps by default)
Right-click | Go back / cancel

# Pixel Grabbing
Hold left-click on an old pixel | Pick it up and drag it
Release | Drop or throw it

# Pixel Bank Hose
Mouse wheel | Choose which stored pixel to use
Left-click | Spit one out
Move the mouse | The nozzle hangs from the ceiling above the spot you point at; the red laser dot shows where it is pointing
Left-click | Drop the selected pixel onto the red dot
Right-click | Suck up the old pixel the red dot is on
Hold right-click | Suck up an area of the selected pixel type
Click a Bank row | Select that pixel type

# UFO Helper (Ride along)
Mouse | Look around the cabin
W A S D / Arrows | Walk about the cabin
Esc | Climb out

# Devices and Minigames
Click buttons 1-3 on the Sorter | Change how hard it spits
Drag the Sorter's force slider | Set exactly how hard it spits (the pipe's end bends it, dragging the ring turns it)
Click a wire (Bomb) | Cut it
Click the ghost or meteor | Collect the reward

# Shop
Shift-click a Value upgrade | Buy as many levels as you can afford

# Crafting
Click or drag an item | Put it in a box
Right-click a box | Empty it

# Log
Click an achievement row | Switch Collector / Clicker

# Dev Tools
Q (when ticked in Dev Tools) | Clear all old pixels

# Menu shortcuts
(blank until you pick one in Settings > Key Bindings) | Open / close Inventory, Shop, Log, Crafting, Toggles, Pixel Bank and Skills (Backspace in the binding screen clears a key)

# Magnetized Sorter
Click an exit pipe, move, click again | Grab the pipe and put its end down anywhere in reach (right-click puts it back)
Mouse wheel over an exit pipe | Choose which stored pixel type that pipe shoots out
Hold left click on an achievement popup | Fills a small ring, then the popup follows the mouse: click to pin it there, right-click to put it back above the combo meter
