# PIXEL TEXTS - the names and hover-card texts of every pixel type. Edit them here; the game reads this file at start
# (or press Dev Hub > Events > 'Reload pixel texts' while playing).

# One section per pixel type. The word in [brackets] is the type's code name - do not change it.
#   name:  the name shown everywhere (hover card, shop, inventory, log...)
#   guide: the explanation on the hover card and in the Pixel Guide
#   husk:  what its husk does (the 'Husk:' line under the explanation). Empty = the general text:
#          'falls beside the cube and lies there for a while before it despawns.'
# Leave a line empty (or delete it) to keep the game's own text. Everything must stay on ONE line: write \n for a new line.
# Rich text works: <b>bold</b>, <i>italic</i>, <color=#FFD27F>colour</color>.
# Numbers filled in by the game: {clicks} (clicks to break), {clicksMin} / {clicksMax} (random clicks), {payMin} / {payMax} (random pay),
#   and for Bait {pellets} {percent} {seconds}.
# The game adds to the hover card on its own: the rarity, the worth, the hits bar, 'Tough: it takes n clicks', the Stall / Block Hold notes
#   and the Husk Crush sentence - those are not in this file.
# Lines starting with # are notes and are ignored. A new pixel type is added to the end of this file by itself (in the editor).
