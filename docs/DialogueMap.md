# Dialogue map (dialogue IDs)

Every 'Got it' box and every character's lines, with a short ID the user can quote ("reword T12.1", "make C1 page 3 shorter"). A letter for the group, a number for the section of `Assets/Resources/Dialogue.txt`, and `.n` for its n-th line in that section. Edit the text in Dialogue.txt (line numbers below); this file is generated by `python3 tools/dialogue-map/build.py`. IDs live in `tools/dialogue-map/ids.txt` and never change.
