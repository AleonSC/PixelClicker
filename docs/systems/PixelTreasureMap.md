## PixelTreasureMap.cs / PixelWhaleFight.cs / PixelOceanSynth.cs

**Fishing's SPECIAL blocks** (a rarer tier beside the base blocks; the same idea is on the to-do for every skill; both are in the Angler's Pack, `packDataVersion` 23, `looksVersion` 48, `PixelType.Bottle` 73 / `Whale` 74, `IsFishBlock`, `BlockSurface.Bottle/Whale` drawn by `PixelBlockTextures.BottleGlass(level,max)` / `WhalePixel`). **Message in a Bottle** (4 clicks, pays 8, weight 0.05, cracks spread per hit): the break calls `PixelTreasureMap.Begin` (sound `bottle_break`; queued one at a time): glass bursts, a UI scroll (canvas 660) flies from the cube to the middle, unrolls between two rollers over a code-drawn parchment map (`MakeMapTexture`: stains, burnt edges, island, palms, compass, you-are-here cube, dotted path and a big red X placed from the real screen positions of the cube and the spot), is read for `readSeconds` (1.8), then shrinks into the spot, where an **X** (two red planks + dirt patch, `Mark`) appears on the ground (`PickSpot`: `spotNearest..spotFarthest` 3-7 pixel widths from the cube, in view, via `PixelBait.FindGround`; up to `maxMarks` 3, fade after `markSeconds`). Clicking the X (`Hot` blocks cube clicks via `ExternalClickBlock`) digs (`dig_x`, dirt FX, a mound grows, the X shrinks); after `digClicks` (6) clicks `PixelClicker.GiveFishingHaul` pays `haulPixels` (10 +-) good fishing pixels at once (bait most often, then seaweed / shells / fish / pearls) and fountains the same old pixels out for show (`dig_done`). **Right-click the bottle** = `PixelClicker.DismissBottle` (no map, no pay). `disableMap`. **Whale** (random 15-100 clicks via `randomClicks`, pays 20 x `RewardMultiplier(need)` = clicks x (1 + clicks x `rewardGrowth` 0.05), weight 0.015): the first MANUAL hit starts `PixelWhaleFight` (not while a takeover / Dash-type minigame is busy; the auto clicker pauses meanwhile, `PixelAutoClicker`): the cube runs from the mouse like Cube Evasion (`fleeRadius` 0.2, `fleeSpeed` 0.55 screen heights per second) with a speed burst ('yank', `yankSpeedFactor` 2.4) on every click and every ~2.6 s (`whale_yank`), a thin fishing line (a `PixelTube` mesh, unlit vertex colours) is drawn from the cursor (on the whale's depth plane) to the whale with a gentle sag and ripple, fully invisible within `lineHiddenWithin` (1 pixel width) of the cursor and fading in over `lineFadeLength` (1.8); `fightSeconds` (80) without landing it = `PixelClicker.WhaleGotAway`; landing it plays `whale_caught` + rings (`OnCaught`), stats `whales.hooked/caught`, `bottles.broken`, `treasure.dug`. `PixelOceanSynth` makes all their sounds in code (`pixel_bottle`, `pixel_whale`, `bottle_break`, `map_unroll`, `map_reveal`, `dig_x`, `dig_done`, `whale_hook`, `whale_yank`, `whale_caught`, `whale_escape`; `PixelAudio.SynthFor` asks it first). The block tooltip also shows 'Clicks left'.
