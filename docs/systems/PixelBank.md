# PixelBank

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

**Intended job (design, not built yet):** the Bank collects husks for their EFFECT, never to cash in later. It is where you keep husks you cannot use yet (e.g. Electric husks before Electrician is unlocked) and spit them out when a machine or use wants them. Under the pixel rules (`PixelRules.md`) a stored husk carries **no payout** (today `BankState.Entry.value` keeps it and a spat-out pixel pays it again; that goes, with a save migration). Capacity stays **one shared total** across all types (`IsFull` = total >= capacity, already the case); the window keeps listing counts per type.

## PixelBank.cs

Pixel Bank (shop pack with `unlocksBank`, Upgrades tab): a **Bank tab docked to the middle of the left edge** (opposite Toggles) opens a window listing stored pixels per type (click a row to select it); the **Bank tab is half width (`bankTabWidthFraction` 0.5)** and a **square hose button** with the drawn hose icon (`DrawHoseIcon`, same picture as the window's hose button) sits on its right, so it is the part that slides out first (`PixelHud.DockInGroup(..., leftOffset, groupWidth)`: both buttons slide as one group; `PixelDockedButton.PointerNear/SlideAmount`); hovering either hose button shows a tip (`hoseTipText`, "click here or press {0}") and, like the **B key**, the button equips the hose. **While the Bank window is open both tabs are tucked away and invisible and the window takes their place at the screen edge; when it closes they fade back in already tucked away (`FadeTab`, `buttonFadeSeconds` 1.2, same as the Toggles tab); a hand-drawn hose icon button at the top left of the window (`BuildWindowHoseButton`) switches the hose on / off (green while on).** Hose = cubic-Bezier tube (`PixelTube.Build`) hanging from the ceiling to a nozzle above the mouse spot. While equipped (`PixelBank.HoseOn`, sets `PixelClicker.ExternalClickBlock` so the cube ignores clicks; Pixel Grabbing and device removal step aside): mouse wheel cycles stocked pixel types, **left-click** spits one (a spat-out vacuum-tier pixel runs `PixelClicker.Vacuum(tier, target, exclude)` like clicking one, but the husks swirl into the SPAT pixel (it keeps flying, they chase it) instead of the cube; `PixelClicker.SpawnStoredPixel`: a real husk with its own tier look and its stored payout), **hold right-click** (`areaHoldSeconds`) = area suction: a ring (`areaRadius`) around the nozzle pulls in husks of the selected type at `areaRate` per second (nothing selected -> the type of the pixel nearest the nozzle; stops when the bank is full); a plain **right-click** sucks up the husk nearest the mouse (within `suckRadius`, any type except fly-away) into the bank (`capacity`; `ReleaseOldPixel` + a fly-in coroutine). **The hose hangs from the CEILING and the nozzle always points straight down** (rewritten: the flick / screen-edge entry point and the X shot arc were dropped as 'wonky'): the mouse ray's first hit (`UpdateHose`, ignoring the main cube) gives a spot, the nozzle hangs `nozzleHeightCubes` (0 = 2.5) main-pixel widths above it (lowered so it stays below the top of the screen), the hose is drawn UNLIT with vertex colours (`HoseVertexColor`: `hoseColor` x a hand-made light from `RenderSettings.sun`, alpha fading to 0 from `hoseFadeStart` (0 = 3) over `hoseFadeLength` (0 = 4) world units above the nozzle - `PixelTube.Build`'s optional `colorOf`), so its top fades out instead of being clipped by the camera; the cubic hose runs from `hoseOffscreenExtra` (0 = 14) units above the nozzle straight down into the swivel ball at the nozzle's back (its top `swayTop` and middle `control` trail behind, `followSharpness`, so it swings). **A thin red laser beam** (`FindBeam`: a Raycast straight down from the mouth + a forgiving SphereCast of radius `suckRadius` / 2 that snaps the dot onto a pixel it brushes; `UpdateAimLine`, `hideAimLine`, `aimLineAlpha` 0 = 0.55, `aimLineWidth` 0 = 0.025) ends in a pulsing red dot (`beamPoint`); `beamTarget` = the husk it is on. **Left-click spits** the selected pixel straight down the beam (`spitSpeed`) onto the dot, **right-click sucks the pixel the beam is on**, hold right-click = area suction in a flat ring round the dot (`areaRadius`; no selection -> the type under the dot). The nozzle is a modelled assembly, scaled as a whole by `nozzleScale` (0 = 1.6; the hose end and the hang height use the scaled length) (`BuildNozzle`, `PlaceNozzle`: hose collar + orange ring, metal body, grip ring, narrowing front with a flared lip and dark opening, built along -Y from the mouth; +X = screen-up side): a **glass cube** (`displaySize`) on a mount on its upper side holds a spinning `CreateDisplayPixel` model of the selected type (real look), and a dark **counter plate** on the camera-facing side of the body carries the stored count as 3D text (`counterText`; a floating text only shows 'Bank full' / 'Bank empty'). The **Bank Storage** shop upgrade (leveled, `UpgradeEffect.BankCapacity`, requires the Pixel Bank pack; 5 levels -> capacity 100/160/250/400/600, paid in glass + vacuum pixels + **bomb parts**) calls `PixelBank.SetCapacityOverride`. A `PackCost` can now spend a minigame counter via `minigameCurrency` (a minigame id; `PixelMinigame.TrySpendTracker`; shop helpers `CanAffordCost` / `SpendCost` / `CostName`). Stored counts and total value per pixel type are progress in the GameState (`PixelGameState.Current.bank`, `BankState`, moved 2026-10-23: saved, loaded and reset with it). Sounds `hose_toggle`, `bank_suck/_spit/_select/_full/_empty`. PixelShop finds/adds it.
