# PixelLog

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelLog.cs

Bottom-left "Log" toggle with three tabs: Achievements, Goals and (since 2026-10-25) **Event log** (`PixelLogEvents.cs`: every event line from `PixelHints`, newest at the bottom, a click shows its full tip; the event log key opens the Log on it; it replaced the on-screen event log box and the Pocket's Event log tab). (the husks / Clicks tab was removed; per-pixel click counts are now in Settings > Stats, 'Clicks per pixel', with `PixelStats.RecentClicks` +N indicators; the code for the old tab is still there but unreachable) - formerly three tabs (the window has ONE fixed size, `FixedPanelHeight`, on every tab; each tab's list scrolls inside it): Pixels (unlocked tiers with how many times each was **clicked** (`PixelTier.timesCollected`, multipliers don't count; overall total; `+1` per click indicators; no vacuum deltas)) and Achievements (scrolling list, **one badge-style row per achievement** (`BuildAchievementRow`: a panel per achievement with a gap between rows, the pixel picture in a framed box, big title, wide progress bar with its '60 / 100' in the middle; **a search box (`achievementSearchField`, `searchPlaceholder`) sits between the total bar and the first heading, same width: it filters by title / description / section and shows matches expanded**; **hovering a row shows a tooltip** (`UpdateAchievementTip` / `AchievementTipText`) saying explicitly whether it counts CLICKING (clicks only) or COLLECTING (everything earned), with progress and tier; the old click-to-switch grouping is gone, `BuildAchievementGroups` makes one group per achievement)) and **Goals** (`RefreshGoalsTab`: progress bars - the next pixel unlock, before Red / Green / Blue an 'earn the Black that brings Cubie's second visit' goal (`PixelGuideVendor.BlackUntilVisitTwo`; Cubie unlocks RGB and opens the shop), then once Red is unlocked and the Shop button shows a **'Purchase the Auto Clicker' goal** (`PixelShop.ShopAvailable` / `TryGetAutoClickerGoal`: bar = price lines saved up, each capped at its own price; `buyRgbGoalFormat/Description`) and, once it is bought and the Toggles tutorial is done, a **Lumberjack's Pack goal** (`TryGetWoodcutterGoal`; both share `TryGetPackGoal`; the old RGB Pack / Combo Meter goals are gone), the `PixelGoals` table goals and Cubie's bill (`PixelCubieBill.NextGoal`), plus every `PixelMinigame` tracker that is running or has progress, e.g. Ghosts Caught, Singularity, Stardust, Meteor Chunks; `goalsTabText`, `goalRowHeight`; **goal rows are badge-style like the achievements** (`BuildGoalRow`: framed live 3D picture of the goal's item via `SkinIcon` (`Goal.skinTier`, `GoalSkinTier(minigameId)`: ghost -> Ghost, blackhole -> Singularity, meteor -> Meteor, stardust -> Solar, next unlock -> that pixel, buy-RGB -> Red; no item = a spinning gold cube), title, wide bar with the count in the middle; the list is as wide as the tab row, the scroll bar sits in the margin; hovering shows the explanation + exact numbers through the shared tooltip, `GoalTipText` / `hoverGoal`); tab content groups are built by the shared `BuildScrollGroup`). Achievement icons show each pixel's real look (`SkinIcon`: rendered once per type with `CreateDisplayPixel` in a hidden studio into a cached RenderTexture; `PixelAchievements.GetSkinTier`; pet achievements too; other achievements keep the spinning `PixelCubeIcon`); the 'click to switch' mode tag is a single non-wrapping line. Has its own local `FormatAmount`.

**Goals table + the early goals ARE the unlocks (2026-10-18):** the Goals tab also lists the rows of `PixelGoals` (`AddTableGoals`, right after the next-unlock goal; data table in the Inspector, header of `PixelGoals.cs`). The built-in rows run the early game: Click 50 blocks -> Cubie's visit 1 (the Recycler), Crush 10 husks (after visit 1) -> Gray unlocks, Recycle 150 husks (after Crush 10) -> Black unlocks, Get a crush streak of 5 (minute 3) -> 60 Standard XP, Earn 300 Black (after Recycle 20) -> Cubie's visit 2 (RGB + the shop). Gray / Black use `TierUnlockMode.ByGoal` (no threshold unlock while a goal unlocks them; the threshold is the fallback), so the next-unlock row skips them and the 'Unlock Red, Green and Blue' row is hidden while a goal grants visit 2 (`PixelGuideVendor.BlackUntilVisitTwo` = -1). The on-screen guide line (PixelUI.BuildGuideText) follows the current goal: 'Crush 10 husks  (3 / 10)  -  Gray Pixels unlock' (`goalGuideFormat`).
