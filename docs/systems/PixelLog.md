# PixelLog

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelLog.cs

Bottom-left "Log" toggle with two tabs (the old Pixels / Clicks tab was removed; per-pixel click counts are now in Settings > Stats, 'Clicks per pixel', with `PixelStats.RecentClicks` +N indicators; the code for the old tab is still there but unreachable) - formerly three tabs (the window has ONE fixed size, `FixedPanelHeight`, on every tab; each tab's list scrolls inside it): Pixels (unlocked tiers with how many times each was **clicked** (`PixelTier.timesCollected`, multipliers don't count; overall total; `+1` per click indicators; no vacuum deltas)) and Achievements (scrolling list, **one badge-style row per achievement** (`BuildAchievementRow`: a panel per achievement with a gap between rows, the pixel picture in a framed box, big title, wide progress bar with its '60 / 100' in the middle; **a search box (`achievementSearchField`, `searchPlaceholder`) sits between the total bar and the first heading, same width: it filters by title / description / section and shows matches expanded**; **hovering a row shows a tooltip** (`UpdateAchievementTip` / `AchievementTipText`) saying explicitly whether it counts CLICKING (clicks only) or COLLECTING (everything earned), with progress and tier; the old click-to-switch grouping is gone, `BuildAchievementGroups` makes one group per achievement)) and **Goals** (`RefreshGoalsTab`: progress bars - the next pixel unlock, a 'Purchase the RGB Pack' goal once the Shop button appears until the pack is bought (`PixelShop.ShopAvailable` / `TryGetBuyGoal(Red, ...)`: bar = price lines saved up, each capped at its own price; `buyRgbGoalFormat/Description`), then a **'Purchase the Combo Meter' goal** once the RGB Pack is bought (`PixelShop.TryGetComboGoal`, bar = first-level price saved up) and, once the Combo Meter is bought (`ComboMeterBought`), a **'Purchase the Auto Clicker' goal** (`TryGetAutoClickerGoal`; both share `TryGetPackGoal`), plus every `PixelMinigame` tracker that is running or has progress, e.g. Ghosts Caught, Singularity, Stardust, Meteor Chunks; `goalsTabText`, `goalRowHeight`; **goal rows are badge-style like the achievements** (`BuildGoalRow`: framed live 3D picture of the goal's item via `SkinIcon` (`Goal.skinTier`, `GoalSkinTier(minigameId)`: ghost -> Ghost, blackhole -> Singularity, meteor -> Meteor, stardust -> Solar, next unlock -> that pixel, buy-RGB -> Red; no item = a spinning gold cube), title, wide bar with the count in the middle; the list is as wide as the tab row, the scroll bar sits in the margin; hovering shows the explanation + exact numbers through the shared tooltip, `GoalTipText` / `hoverGoal`); tab content groups are built by the shared `BuildScrollGroup`). Achievement icons show each pixel's real look (`SkinIcon`: rendered once per type with `CreateDisplayPixel` in a hidden studio into a cached RenderTexture; `PixelAchievements.GetSkinTier`; pet achievements too; other achievements keep the spinning `PixelCubeIcon`); the 'click to switch' mode tag is a single non-wrapping line. Has its own local `FormatAmount`.
