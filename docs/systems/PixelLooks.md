## PixelLooks.cs

**Editing looks in game:** the Look Studio (`PixelLookStudio.cs`, Dev Hub tab 'Looks') edits any type's `PixelLook` at run time and exports it as a `new PixelLook { ... }` line. To make an exported look official: put the line in `PixelLooks.CreateDefaults` (replacing the type's old entry) and add a `looksVersion` step in `PixelClickerLookFixups.cs` that replaces that type's saved look; apply the export's Block values to the tier's defaults. A new `PixelLook` field shows up in the studio by itself; add its name to a section in `PixelLookStudio.Sections`.

Per-pixel-type 3D look, separate from the tier data (the UI keeps the tier colour): `PixelLook` list on `PixelClicker` (`looks`, `useLooks`; defaults from `PixelLooks.CreateDefaults()`): colour override + alpha, **the basic pixels (White, Gray, Black, Red, Green, Blue) have a subtle drawn surface (`PixelLook.basicSurface`: Grain / Brushed / Sheen / Mosaic via `PixelLooks.BasicTexture`, near-white 128 px textures that multiply the colour) (Obsidian and Seed have the same bevel rim, shade taken from their tier colour via `outlineShadeOfTier`: Obsidian -0.55 (dark, `looksVersion` 24), Seed -0.4; `looksVersion` 20) and a thin rim (`PixelLook.outlineBevel`: a flat rim on every face along its four borders, mitred at the corners, solid at the cube's edge and fading inwards (`AddBevelRims`; no overlapping boxes, nothing sticks out) - no neon halo / white core - `EdgeMesh(..., bevel)`) that is a different SHADE of the pixel's own colour (`PixelLook.outlineShade`: above 0 lightens towards white, below 0 darkens towards black; White -0.3, Gray / Red / Green / Blue +0.4, Black +0.3; thickness ~0.027, strength ~0.5); Black is drawn in a slightly lighter near-black so the sheen shows; `looksVersion` 21 gives them a material feel (White matte 0.35, Gray brushed metal 0.65 / 0.55, Black glossy 0.85, RGB glossy 0.6 + faint emission 0.12; revertible as one commit) ; `looksVersion` 17 adds / updates them in saved lists (18 switches the rim to the shade, 19 to the flat bevel) (a Red/Green/Blue look you already edited is left alone)**, metallic/smoothness, plain emission, neon edge outline (no pixel type uses it by default now; runtime-built mesh of 24 thin boxes with vertex colours, `Sprites/Default` material), surface texture (`streakTexture` white streaks on black, `damageCracks`: cracks that spread with every hit on a tough pixel, drawn by `PixelLooks.SurfaceTexture` and set per hit via `PixelClicker.SetLiveDamage`; used by Obsidian; the live cube's property block is cleared in `ApplyTierLook`), jelly `wobble` (live cube scale in `AnimatePixel`; falling copies draw on a child `Wobble Visual`), old-pixel physics per look (`customPhysics`: bounce/friction/`gravityMultiplier`; `ignoreViewBounds` read by `PixelViewBounds` via `PixelClicker.IgnoresViewBounds`; `floatAway` -> `OldPixelFloat`: after N ground bounces it stops colliding, drifts up/sideways and is removed off-screen; used by Ghost; a floating ghost is kept above the floor in `OldPixelFloat.FixedUpdate` so a gravity well can't drag it through the ground), gravity well (`gravityWell`, `wellRadius`, `wellPullSpeed`, `wellGrip`, `wellRingOpacity`: `OldPixelGravityWell` drags other old pixels toward it at a constant speed (overrides floor friction; works while carried with Pixel Grabbing) while it is at full size, plus a very faint camera-facing ring sprite; used by Singularity, whose spawn weight is 0.08; **each well holds at most `wellMaxPixels` (20) pixels at a time**: it keeps the nearest unclaimed old pixels in its radius (a pixel is claimed by one well only, `OldPixelGravityWell.claims`), other Singularity pixels inside the radius count towards the 20 so wells packed close together starve each other and have to be spaced out; the well pixel itself lasts `wellLifetime` = 300 s (5 min, set in the well's `Start` via `OldPixelDespawn.SetLifetime`) and every old pixel inside its pull radius is kept alive by `OldPixelDespawn.KeepAlive()` each physics step, so it doesn't age while the well works; a flying meteor pixel within `wellFlyReach` (4) pull radii is steered towards the well (turn rate 5 rad/s, slowed) and, once inside the ring, captured: `PixelClicker.LandFlyingPixel` + its speed cut to 20%, then it is dragged in like the others), face circles (flat black discs on the 6 faces, used by Vacuum; `faceRing` + `faceRingColor` draw each as a vortex: black centre, a glowing violet ring that fades outward (`PixelLooks.VortexMesh`), plus a violet bevel rim and faint emission, `looksVersion` 22), dark-matter core (counter-spinning cube with a runtime swirl texture), `lightning` (Electric: `PixelLookLightning` builds a dynamic mesh of jagged crossed-ribbon bolts along the 12 edges + a few arcs through the inside, re-rolled ~12x/s on unscaled time, a wide soft glow pass + a thin bright core pass, simpler when more than 6 exist; unlit vertex colours via `OverlayMaterial`; `lightningCoreColor/GlowColor/Jitter`), `forceTranslucent`, and `shatter` (glass: `OldPixelShatter` breaks the old pixel into `OldPixelShard`s when it hits the ground; the pixel is removed without payout; sound `glass_shatter`). Live-cube extras are managed by `PixelClicker.UpdateLiveExtras`; old pixel copies get them in `SpawnFallingCopy`.
