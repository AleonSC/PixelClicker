# PixelToggles

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelToggles.cs

Toggles window: a button docked to the **middle of the right edge** (`PixelHud.Dock` with anchor (1, 0.5) = side docking, slides sideways) stays hidden until the Auto Clicker is bought (`hideUntilAutoClicker`) and opens a window with a group selector (Pixels / Upgrades / Minigames / **Vendors** / Pets (**skill packs are never listed here - the Skills window chooses the pack in play; do not add skill-pack switches (Mining / Farming / Electrician mode) to Toggles**) (Vendors = the visitor minigames `PixelVisitorMinigame`, filtered out of Minigames; tab names are `tabNames`): a **drop-down while docked beside the open shop**, where the window copies the currency panel's width and the shop's height (`FitBesideShop`), **tab buttons when it stands alone**; `besideShop`, `ApplyGroupControl`) over a scrolling list of tick-box rows (**no visible scroll bar**: `PixelScrollBarFade.hideBar`; the wheel and bottom fade still work). **The tabs are pixel-art icons drawn in code (`PixelTabIcons`: three cubes in a triangle, a machine with a green up arrow, a joystick + Pac-Man, a market stall with a person, a cat + a dog), used both beside the shop and standing alone (the drop-down is no longer shown); hovering one shows its name in a small tip (`UpdateTabTip`)**. Pixels = `SetSpawnEnabled` for switchable unlocked tiers; Upgrades = `PixelAutoClicker.UserDisabled`, `PixelGrab.UserDisabled`, `PixelTimeStop.UserDisabled` and `PixelCombo.UserDisabled` (all saved by PixelSaveGame; `Working` = bought and not switched off); Minigames = `PixelMinigame.UserDisabled`. Rows are sorted alphabetically (`Collect` result sorted by label). Every tab with two or more switches starts with a **'Toggle all'** row (`toggleAllText`; ticked while everything is on; `skipAll` entries are modes rather than on / off items; no skill pack is listed in Toggles any more). **This replaced the tick boxes that used to sit on shop rows.** Buying the Auto Clicker pack no longer switches it on: `PixelShop.TryBuy` sets `PixelAutoClicker.UserDisabled = true` and calls static `PixelToggles.ShowHint()` (a hint box next to the slid-out tab telling the player to tick Auto Clicker under Upgrades; closes on "Got it" or when the window opens; the tab stays out while it shows). Dev "Skip intro" / "Unlock all" still switch it on. The pause menu adds this component if missing.
