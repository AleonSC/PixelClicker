# PixelConsumables

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

**Inventory progress (2026-10-24):** what you hold (`Potion.owned` / `bonusCap`, `Device.owned`) lives in the GameState (`InventoryState`, by key; see `docs/systems/PixelGameState.md`); placed devices and the running potion copy themselves in on `PixelGameState.Saving` and are rebuilt on `Loaded`. Overrides older save wording below.

**Device models (2026-10-24):** each device builds its own look in its own script: `PixelFanDevice.BuildModel` (+ `WedgeMesh`), `PixelVacuumDevice`, `PixelMagnetDevice`, `PixelSprinklerDevice`, `PixelLightningRod`, `PixelChargeBooster`, `PixelQuantumDevice`, `PixelStorageCrate` (all `BuildModel(clicker, root, device, isPreview, previewOpacity)`). `BuildDeviceObject` here only picks one and adds the shared range disc, suction point and timer. A NEW device's model goes in its own script the same way (the newer machines already use `CreateGhost` / `CreateDisplay` / `Place`).

## Attuned devices (PixelConsumables.AppendAttunedDevices, PixelCrafting.FindAttuneRecipe)

**Crafting a Vacuum Device, Fan or Magnet with a plain (single-type) potion** (`ResultKind.Attuned`, any box order, uses up one of each) makes an **attuned** copy that only affects husks of the potion's pixel type. For every potion type a craft-only `Device` clone (`attuned`, `attuneType`, name 'Attuned <device> (<Type>)', colour tinted by the pixel) is appended at runtime AFTER all normal devices (so indexes never shift; `FindDeviceOfKind` skips them; `ItemAttuned`, `FindAttunedDevice`); the saves keep only the ones you hold. `PixelPlacedDevice.AttuneTier` / `Accepts(body)` (set in `SpawnDevice`) is checked by the Vacuum / Fan / Magnet FixedUpdate. The crafting materials list always shows those three device kinds (when held).

## PixelConsumables.cs

Potions (one per pixel type, editable list: name, type, costs, duration, owned) and placeable devices (Vacuum Device: right-click in inventory → cylinder follows mouse → left-click floor to place; right-click cancels). Unified `Item*` accessors (potions first, then devices) used by shop/inventory/save. Drinking one calls `PixelClicker.SetForcedSpawnTier` for its duration. **Instant-use items** (the **Supplies** category: `IsSupplyItem`, `CategoryOf` 0 potion / 1 device / 2 seed / 3 supply; a Supplies card in the shop's Consumables tab (`suppliesCardTitle`) and a 4th Inventory category) are devices of kind `ComboFuel` / `GhostBait` / `PetTreat` (not placed; `Device.maxHeld` = hold limit, 0 = unlimited, drives `ItemCapacity` / `ItemRoom` / `ClampDeviceHeld` and the shop's Full text; defaults auto-added to saved scenes like the fan): **Combo Fuel** (hold 3) is used automatically by `PixelCombo` when the timer bar would run out (`TryUseAutoItem`): the combo is kept, the bar rebuilds over `fuelRefillSeconds` in `fuelBarColor`, a click ends the refill, otherwise it then runs down normally. **Ghost Bait** (hold 1; right-click in the inventory = `TryUseItem` -> `PixelGhostMinigame.UseBait`, needs the minigame running): the next ghost comes within `baitFirstDelay` and `baitGhosts` (3) ghosts follow `baitGap` apart, each crossing `baitSlowFactor` times slower. **Pet Treat** (hold 5; right-click -> `PixelPets.TryUseTreat`, needs a pet out): for `treatSeconds` (60) pets are hyper (hop `treatHyperFactor` x as often, a bit harder; the Ghost pet drifts faster), glow (a point light + halo child "Treat Glow") and the extra spawn chance they give is multiplied by `treatExtraFactor` (2). **Seeds** are devices of kind `Seed` (`Device.seedType`, one per growable pixel type, auto-added after the other devices by `EnsureDefaultPotions`; not Meteor / Seed / Dragon Cubes; `IsSeedItem` / `SeedTypeOf`): price worked out in `ItemCosts` from the pixel's payout (`seedPriceFactor` 3 x `amountPerClick` x Value multiplier x (1 / spawn weight)^`seedRarityPricePower` 0.5, min `seedMinPrice` 3, paid in that same pixel, so low tiers are cheap and rare ones dear), hold limit `seedMaxHeld` 200; right-click in the Inventory (Consumables > **Seeds** category) = placement mode like devices (a sprout preview follows the mouse; each left click on the floor plants one via `PixelClicker.PlantSeedSproutAt(point, tier)` -> a `SeedSprout` that grows exactly that pixel type (`SeedSprout.ForceTier`), keeps planting while seeds remain, right-click / Escape stops; stat `seeds.planted`); excluded from the Tinkerer and the Gadgeteer achievement. PixelShop sells them (Consumables tab); PixelShop auto-adds this component if missing.

## Prices (repriced 2026-10-17, design in docs/GameDesign.md section 8)
- Every pure-currency device costs 2-3 of the six pure colours: monochrome (White / Gray / Black) for machines, RGB for boosts and timed items, one RGB accent allowed on a machine. Priced in minutes of income (the 10:50 session report: White 113, Gray 85, Black 80, Red 135, Green 128, Blue 160 per minute): a cheap tool ~1 minute of each colour it costs, a milestone tool ~3-5.
- Skill items (Wood Chipper, Bait Bucket, Conveyor Belt Kit, Lumberjack's Focus, Pesticide Spray) stay in their skill's blocks; costs in a pack's own material (Glass, Electric, Water, Vacuum, Obsidian) are kept. Potions and seeds are priced at run time from their pixel's output (`potionPriceFromOutput`, `seedPriceFactor`), in that pixel.
- The Recycler's price doubles for each one held or standing (`priceGrowthPerOwned` 2).
- The coded defaults reach a saved scene through `consumablePriceVersion` (1 = this repricing) -> `ResetDefaultDevicePrices` (also the context menu 'Reset Built-in Device Prices'); `DefaultDeviceMakers` is the one table of built-in device kinds. Bump the version after the next repricing.

## Dev Tools-only devices (2026-10-18)
- `Device.devOnly`: never sold by the shop or a visitor (`ItemNotSold` covers it, so the shop tabs, search, TryBuyItems and visitors' wares all skip it); Dev Hub > Main > **Dev items** widget gives one (`PixelConsumables.ItemDevOnly`). Saved scenes took the flag through `consumablePriceVersion` 2.
- Dev-only now: Quantum Organizer, Funnel, Sprinkler, Vacuum Device, Bait Bucket, Conveyor Belt Kit (the kit is also placed from Dev Hub > Tester > Conveyor Belt). Attuned Vacuum Devices still exist in Crafting but need a Vacuum Device from the Dev Tools.


**Fixes 2026-10-20 (audit).** Buying several of an item at once adds up its rising price step by step (`ItemCostsTotal`, used by the buy bar, Max and `TryBuyItems`). Held counts are cut to their caps only after the Operation Storage levels have loaded (the inventory part keeps the saved counts; the world part's Import clamps, `ClampAllHeld`). Potion, combo and attuned names and `{pixel}` use the tier's display name (`TierName`). Device texts can use `{held}` (the cap incl. Storage), `{charges}` (Pesticide Spray) and `{uses}` besides `{radius}` / `{duration}`; scene-stored texts are switched to these placeholders and to 'husk' wording on start (`UseDescriptionPlaceholders`). Drinking a potion while one runs says so in the event log. The Inventory item tooltip shows the item's name, description and how to use it. The category is called Utilities everywhere. Devices the UFO places stay switched on (its job); dev-placed ones start disarmed like the player's (`StartsDisarmed`). The Bait Bucket (`baitBucket`) and the running Focus potion (`focus`) are saved.
