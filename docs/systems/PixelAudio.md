## PixelAudio.cs

Sound system. **Alt-tab keeps the music track:** `OnApplicationFocus` pauses the music source on focus loss and resumes it (same position) on return (`musicHeldByFocus`); **`UpdateMusic` also remembers the playing clip / time every frame (`musicLastClip` / `musicLastTime`) and, when the source has stopped mid-track while the app is focused, resumes that clip at that time instead of picking a new random track** (and never picks a track while `!Application.isFocused`). Named `Sound` list (id, clips[] picked at random, volume, pitch range, cooldown) filled in the Inspector - an empty/unknown sound is silent; music tracks (shuffle/loop); Master/Effects/Music volume + mute (saved in PlayerPrefs, sliders in the pause menu's Settings via `PixelUIKit.CreateSlider`); a voice pool; looping sounds via static `PixelAudio.StartLoop(id)`/`StopLoop(id)` (first clip of that sound, fades by `loopFadeSeconds`). Plays by itself from existing events (clicks `click`/`auto_click`/`pixel_<type>`, `hit`, `vacuum`, `pixel_land` (from `OldPixelImpact` -> static `PixelClicker.OldPixelLanded(intensity)`; volume scales with impact speed), `combo` (pitch rises), `purchase`, `craft`, `drink`, `device_place`, `achievement`, `<minigame id>_spawn/_click`, `ui_click` from every `PixelUIKit.CreateButton` (the shop adds its own), `ui_scroll` from `PixelScrollSound`, a pixel type's own bounce `pixel_bounce_<type>` (e.g. `pixel_bounce_electric`: `OldPixelImpact` plays it, volume by impact speed, instead of `pixel_land` when that sound has clips; Electric's ships as a code-synthesized crackling zap, `PixelSynth.Zap`, used only while the sound's clip list is empty - assign your own clips to replace it) which is added to every ScrollRect the game builds); other code calls `PixelAudio.Play("id")`. `PixelAudio.Stop("id")` cuts off every voice still playing that sound (used by Time Stop / Time Slow when time resumes). The older per-script sound slots (purchaseSound, drinkSound, craftSound, caughtSound, hitSound) still exist. The pause menu adds this component if missing.


**Track choice:** `MusicTrackCount` / `MusicTrackName(i)` / `CurrentMusicTrack` / `SelectMusicTrack(i)` (starts the track now, shuffle / order carries on after it); used by the main menu music selector (`PixelTitleMusic.cs`).


**Shuffle / playlist:** the FIRST song after the game loads is always random (then `shuffleMusic` decides: random or in order). Settings > Audio > "Custom playlist" (shown with 2+ tracks) opens a checklist screen (`PixelPauseMenu.BuildPlaylistPanel`): only ticked songs play (`IsTrackEnabled` / `SetTrackEnabled` / `EnableAllTracks`, PlayerPrefs `PixelAudio.PlaylistOff` = unticked clip names, so new songs start ticked); the last ticked song cannot be unticked. The main menu selector can still start any song.


**Per save (PixelSettingsSync):** `MusicMuted` (the speaker button next to the main menu music selector + Settings > Audio "Mute music"), the custom playlist (`PixelClicker.Setting.PlaylistOff`) and the chosen song (`PixelClicker.Setting.Song`, set by `SelectMusicTrack`; on startup / save load that song plays instead of a random first pick). Named `PixelClicker.Setting.*` so a new game resets them. **Old pixel vanish:** `OldPixelDespawn` plays `pixel_vanish` (code-made `PixelSynth.Bloop`: a small high upward chirp, quiet, 0.04 s cooldown, pitch 0.88-1.3) when the shrink ends.


**Playlist preview / speaker right click:** each song row of the custom playlist has a small play button left of its tick box (`PreviewTrack(i)` plays ~8 s starting 30% into the song on its own AudioSource, the music goes quiet meanwhile, again = stop, closing the checklist stops it). Right clicking the main menu speaker opens Settings > Audio directly (`PixelPauseMenu.OpenAudioSettingsFromTitle`: Audio section unfolded and scrolled into view).

**Music cues (`PixelAudioCues.cs`, partial class `PixelAudio`):** the gameplay music changes at triggers and fades in / out - an Inspector list `Music Cues` (name, trigger Minigame / Skill / Night / FirstPerson / UfoRide / TitleScreen / Manual, param, priority, clip or playlist track number, volume, loop, fade in / out). The highest-priority true cue plays on its own AudioSource while the playlist fades down and is PAUSED where it was, then resumes when no cue is wanted. Built-in cues (Night, Ghost hunt, Bomb, Black hole, Evil tree, UFO ride, God find, Dragon wish) are added by name WITHOUT music - assign clips to the ones you want. `PixelAudio.SetMusicCue(name, on)` switches a Manual cue (the God Cube shows and the Dragon wish do). `disableCues`, `addDefaultCues`.

**Music tempo / beat (`TryGetMusicBeat`):** `musicTempos` (Inspector list: clip, bpm, firstBeatSeconds) gives each song its tempo; songs not listed use `defaultMusicBpm` (90) with the first beat at 0 s. `PixelAudio.Instance.TryGetMusicBeat(out double beat)` returns where the audible music (the cue's source while a cue plays, else the playlist's) is in beats, from the source's sample position; false while no music plays. Used by the main menu cube show (`PixelTitleCubeShow.cs`), which changes block on each beat.
