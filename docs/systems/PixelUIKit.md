# PixelUIKit

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelUIKit.cs

Shared static helpers for code-built UI: `EnsureEventSystem`, `CreateCanvas`, `CreateText`, `CreateButton`, `Stretch`, `CreateDropdown` (arrow = a drawn triangle sprite), `CreateInputField` (white 3 px blinking caret, placeholder hidden while focused), `AddSearchIcon(field)` (magnifier inside a search box; used by every search box), `Caps(label|button)` (UpperCase font style: **every window title and tab label is shown in capitals**), arrow buttons (`UseArrowGlyph(button, pointLeft)` swaps a "<" / ">" letter for a drawn triangle: the shop's Back button in the sub window (Pixel Bank / Auto Clicker upgrades), the floor / sky pickers, the pet outfit arrows), **UI colour** (`PixelUIKit.UiColorOn` / `UiHue` / `UiSat`, PlayerPrefs `PixelClicker.Setting.UiColor/UiHue/UiSat`, Settings > Interface, synced per save; **there is no slider: an eyedropper button beside the 'Custom UI colour' tick box picks the colour from the screen** (`SetUiColorFromColor` takes its hue and saturation, switches the colour on): `Tinted(colour)` keeps a window colour's brightness but gives it the chosen hue; `StyleWindow` remembers every window image so `RefreshWindows()` recolours them live), **bar glow colour** (`PixelHud.GlowHue` / `GlowCycle`, `PixelBarGlow.EdgeColor(baseHue, time, speed, offset, sat)`), **boxes** (`PixelUIKit.StyleBox(image, inset)`: rounded, softly shaded list rows / cards with a thin lit rim, `inset` = a sunken frame for 3D pictures; used by the Shop rows, currency rows, cards and picture frames), **fancy windows** (`PixelUIKit.StyleWindow(image, colour)` gives every window background a code-drawn rounded 9-slice frame with the colour baked in - gradient, bright cyan rim, inward glow; always on (the old flat-window switch and its Settings toggle were removed); **new windows should call `StyleWindow` instead of setting `Image.color`**), **fancy buttons** (always on, the flat-button switch was removed: `CreateButton` uses a code-drawn grey-scale 9-sliced `ButtonSprite` - rounded corners, dark outline, gradient, light top strip - tinted by the button colour; the shop's own button builder calls `PixelUIKit.StyleButton` too), close buttons (a button labelled "X" draws a cross sprite via `UseCloseGlyph`; the shop's own `CreateButton` does the same), `TickSprite()` (code-drawn check mark used as the fill of every tick box), `CreateScrollView`/`UpdateScrollView` (masked scroll list + auto-hiding scroll bar). **Every scroll bar uses `PixelUIKit.StyleScrollBar(track, handle)` (slim `ScrollBarWidth` 10, rounded dark track + lighter rounded handle): new scroll bars must call it. **Bottom fade:** while a list scrolls and isn't at its end, `PixelScrollBarFade` fades the ROWS (direct children of the scroll content, each given its own `CanvasGroup`: alpha follows the row's centre height above the view's bottom edge, `fadeHeight` 44 x 1.6) plus a bobbing chevron below the list; nothing is drawn over the window and the mask is untouched (an earlier soft-mask version let rows ghost over the tabs at the top). Not for drop-down templates or views without a RectMask2D. `StyleScrollBar` also adds `PixelScrollBarFade` (CanvasGroup alpha: visible while scrolling / hovered / held, `holdSeconds` 0.45 after the last movement, then fades in `fadeSeconds` 0.18). UI scripts delegate to it instead of carrying their own copies.
