## Layout since 2026-10-24: the catalog (read this first)

The shop window is 1240 wide (`panelWidth`, migrated by `tileLayoutVersion` 3) and laid out as the "A + Saving up" design from the Shop Redesign canvas: title top left, search box beside it, IOU / ? / X on the right; no currency row of its own: opening the shop opens the **pinned Inventory** (switched to its pinned currency view while the shop is open) and closes the Log; closing the shop closes it and restores the Inventory's view; the player can put it away while the shop stays open (`PixelShopCurrency.cs`, `PixelUI.ShowPinnedBesideShop`); the **category rail** on the left (`PixelShopCatalog.cs`: Pixels > Toggleables / Skill packs, Consumables > Utilities / Potions / Seeds / Supplies, Upgrades > Features / Value / Operation, Minigames, each with a count) - it replaced the four tabs, the filter chips and the Upgrades sub-tabs; the **Saving up for card** (pinned item, per save `Shop.SavingGoal`, else the unlocked pack you are closest to affording); a heading row with **Only what I can buy**; the **tile grid** (named tiles, green can-buy bar) and the **detail panel** (`PixelShopTilePage.cs`: cost with what you hold, - count + and x1 / x5 / x10 / MAX for consumables and Value levels, Save up for this, Buy that says "Need more X"). Every kind of thing is a tile (packs, consumables, Value upgrades, Operation devices - ids by range, `PixelShopSearch.cs`). The old tab bar is not built; the scrolling row list stays only for the pack Upgrades window (`classicWindowWidth` 900, also the Crafting window's width via `PanelSize`). Windows docked beside the shop (Pixel Guide) narrow to the room left (`PixelUIKit.FitBesideShop`). **Older notes below describe the tabs / chips / buy bar / currency panel layout and are history.**

## PixelShop.cs / PixelShopUI.cs / PixelShopDefaults.cs

One `partial class PixelShop` in three files: **PixelShop.cs** = data types, ALL `[SerializeField]` settings, lifecycle, buying/requirement logic; **PixelShopUI.cs** = building and refreshing the UI (button, panel, tabs, scroll list, upgrades window, trackers); **PixelShopDefaults.cs** = the built-in pack definitions (`Create…Pack`) plus the `BuiltInPacks` table (how to recognise each one, which pack it requires, how to build it) - **to add a built-in pack: write its `Create…Pack` and add one line to the table**. Keep new serialized fields in PixelShop.cs so the Inspector order stays stable. Shop button (appears once `requiredTier` = Black is unlocked) + panel. ## Packs kept out of the shop (`ShopPack.hideInShop`)

`hideInShop` leaves a pack out of every shop list (`PixelShopUI.HiddenAsPurchased` returns true for it) while it keeps existing and working. Set (by the builders and `packDataVersion` 33, `PixelShop.IsDevOnlyPack`) on the testing packs: Fire Pixel, Nuclear Pixel, the Farmer's Pack and the Prospector's Pack (packDataVersion 34; so Farming and Mining are reachable only through Dev Tools for now), and on Block Hold (free from the start). Untick it in the Inspector to sell a pack again. Unlock / relock them with the Dev Tools **Shop unlocks** widget (`PixelShop.DevUnlockPack` / `DevRelockPack` / `DevUnlockAllPacks` / `DevRelockAllPacks`; relocking also locks the pack's reward pixels with `PixelClicker.LockTier`).
- Upgrades tab order: the Pixel Bank is shown right above Time Stop (PixelShopUI display sort only; the pack list keeps its indexes because requirements point at them).

**RGB is an unlock (2026-10-16):** the RGB Pack is `hideInShop` and given for free by Cubie's second visit (`GrantPackRewarding(PixelType.Red)`) at 100 Black earned; the Shop button appears with Red (`requiredTier` Red, packDataVersion 40); the Auto Clicker costs 150 of each pure pixel and is the first Log goal after RGB (the RGB and Combo Meter goals are gone); the Lumberjack's Pack (250 each) follows.

**Shop rebalance (2026-10-16, shopBalanceVersion 1 = ResetBuiltInPackPrices once + minigame packs lose their requirements):** prices follow the early-game path from the session reports (about 40 of each pure colour per minute early, more with Value / potions / auto clicking). Tiers (each = of all six pure pixels unless noted): ~5-10 min Auto Clicker 150; ~10-20 min Lumberjack 250, Combo Meter 400, Faster Clicking 500, Husk Capacity 600, Forager 500 (W/G/B), Angler 800 (W/R/B), Snake 1.2K, Prospector 1.2K (W/G/B), Seed 1.5K RGB, Multi-Click 1.5K; ~20-60 min Cube Dash 2K, Electric / Electrician 2.5K RGB, Bomb 2.5K RGB, Farmer 2K (W/G/R/Gr), Glass 3K, Cube Blink 3.5K, Bank 5K, Sorting Race / Evasion 5K, Mirror 6K RGB, Red Light 7K, Treasure 8K W + 4K B; ~1-3 h Breakout 12K, Vacuum 2K Glass + 12K RGB, Time Stop 15K, Ultra Holes 15K, Obsidian 20K B + 5K Glass, Time Slow 50K, Black Hole 60K B + 8K Vacuum; later UFO Helper 150K, Luminescent 20K Glass + 60K Obsidian, Meteor Strike 150K B + 200K Obsidian, and the special pixels (Ghost / Meteor / Solar / Singularity) about a tenth of their old prices. Leveled upgrades (Combo, Faster Clicking, Husk Capacity, Multi-Click, Bank Storage) got a gentler first level. MINIGAMES need only their price now (no pack requirements; ones priced in Glass / Obsidian / Vacuum / Wood still come after those pixels). A first pass - check it against session reports.

**Shop text file (2026-10-18):** every pack's and built-in device's name, description and price can be edited in `Assets/Resources/ShopText.txt` (PixelShopText.cs; `PixelShop.ApplyShopText` in PixelShopDefaults.cs, `PixelConsumables.ApplyShopText`). The file wins over the Inspector at play; blocks are keyed by the coded default name; the Editor writes missing blocks on play. Potions and seeds are priced at run time and are not in it.

**Skill pack price ladder (2026-10-24, GameDesign section 6 'Tier 0'):** the gathering packs (Lumberjack's, Forager's, Angler's, Prospector's, Farmer's; `ShopPack.skillLadder`) are priced by `PixelShop.LadderCosts`, not by their typed costs: `skillLadderStarterPrice` (250) of EACH pure colour x `skillLadderGrowth` (2.5) ^ rung, two significant figures (250 / 630 / 1.6K / 3.9K / 9.8K). By purchase order (`skillLadderByPurchaseOrder`, on): the Nth pack you buy costs rung N-1, whichever it is; `skillLadderStarterFixed` (on) keeps the Lumberjack's Pack at rung 0 and every other pack at rung 1 or more. Saved packs took the flag through `shopBalanceVersion` 2. The Electrician's Pack is not on the ladder (a making / operation skill: input-skill levels will open it). ShopText.txt prices are ignored for ladder packs.
