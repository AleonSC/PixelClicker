## PixelRobotWorker.cs

**UFO Helper** (class and shop pack keep the old name 'Robot Worker' so saves keep working; shop pack `unlocksRobot`, Upgrades tab, 1M each; `PixelShop.robot` found/added like the bank; `Activate/Deactivate`): a small code-built flying saucer (hull, rim, glass dome with a green alien, spinning rim lights; fixed size `robotScale`) that **idly hovers about the map** (always higher than the cube - world height at least 1.4 pixel widths over the cube's centre and higher up the screen than it; no text label over it; `UserDisabled` switch in Toggles > Upgrades, saved as `SaveData.robotDisabled`; `hoverHeight` pixel widths above the floor height `floorY`, `PickWander`: random spots round the cube between `minDistanceFromCube` and `maxRoamDistance`, on screen, and at least `minScreenGapFraction` of the screen height from the cube ON SCREEN so it is never above it; new spot every `wanderMin..MaxSeconds`; smooth velocity `flySpeed`, bob, leans into its flight; stops while hovered so it can be clicked) with a **speech bubble showing an alien face** floating over it (`BuildBubble`, clamped to the screen, also a button that opens the window). **Click-through:** while the mouse is over the saucer or its bubble both fade to `hoverAlpha` (parts swap to transparent materials, `UpdateFade`), left clicks pass through (`PixelRobotWorker.Hovering` stays false, the bubble is not a raycast target) and a RIGHT-click opens the window (`BuildWindow`, canvas 520, `PixelWindows` priority 55) listing the placeable devices (`PixelConsumables.IsPlaceableKind`: Vacuum, Fan, Charge Booster, Lightning Rod, Sprinkler) with the counts you hold. Picking one starts a normal ghost placement (`PixelConsumables.BeginRobotPlacement`, nothing is used up) and the chosen spot becomes the job (`SetJob`, a persistent see-through ghost via `PixelConsumables.CreateGhost`). Every `checkInterval` it looks whether a non-ending placed device of that index stands there (`IsOccupied`) and, when not and you hold one, flies to `workHeight` above the spot (for the Sorter beside the cube, `sorterStandOff`), switches on its **abduction beam** (`BuildBeam` / `UpdateBeam`: a see-through cone with vertex colours, `beamColor`, flicker, from the saucer's underside to the spot) for `placeDelay` s, then `PixelConsumables.RobotPlace` puts the device down already armed (uses one up; stat `robot.placed`) and `DropDevice` slides it down the beam over `dropSeconds`. Out of stock -> red label, it goes back to wandering. **The window** (780 x 780, a scroll list of `AddRow` rows: name left, count right ('Unlimited' for infinite, red when 0), hover highlight; two pages `windowPage`: devices and, with the Pixel Bank bought, 'Abduct a pixel into the bank' -> a list of unlocked pixel types with how many are banked; footer Back / Stop working). **Bank job** (`bankJob` / `bankType`, `UpdateBankJob`): it flies over the nearest loose husk of that type (`FindBankTarget`: not kinematic, not held), holds the beam on it for `abductSeconds`, then `PixelBank.StoreOldPixel(body, undersideOfSaucer)` / `IsFull` pulls it into the saucer and banks it; idles (wanders) when none are left or the bank is full (labels 'Bank full' / 'Needs the Pixel Bank'); stat `robot.banked`. The job is saved as a string (`Export/Import`, `SaveData.robot`, device by name). Renamed text fields (`ufoTitle`, `ufoJobSetFormat`, `ufoBankJobFormat`) so old serialized texts are dropped. **Screen saver** (`PixelRobotSaver.cs`, same partial class; `disableScreenSaver`, `saverIdleMinutes` 0 = 3, `saverCheckInMin/Max` 0 = 2-5 min, `saverRoamSeconds` 0 = 20, `saverSpeedFactor` 0 = 1.6): with no input (`PixelInput.AnyInputHeld`, pointer move, wheel) and no job / open window for the idle time it flies up out of view above the camera (`Leaving` -> `Away`); each check-in does a `FlyBy` across the top of the screen or a `Roam` visit (normal wandering) then leaves again; any input drops it back to normal wandering; the speech bubble hides while it is off screen; `UserDisabled` set (off or on) calls `ResetSaver` so toggling it off and on respawns it on screen. **Ride along** (`PixelRobotCockpit.cs`, same partial class; first row of the UFO window, `boardText`; `PixelRobotWorker.Piloting` makes `ExternalClickBlock` true and blocks Pixel Grabbing / first person): the glass dome holds a small cabin built in `BuildUfo` (floor + ring, a 16-panel ring console with 32 blinking buttons `consoleButtons`, a console screen, a round glass WINDOW in the cabin floor (hull / underside are lathe meshes `MeshPrim` / `LatheMesh` with a hole of `WindowRadius`, a dark shaft between, a transparent floor disc) so you can look down through the saucer, a tiny alien at a station, a `cabinLamp` that is only on while riding). Choosing the row puts you inside as a passenger: the camera (`UFO Passenger` root object, `CopyFrom` main camera, main `cullingMask` 0) sits at `bodyT.TransformPoint(walkPos, CabinFloorY + eyeHeight)` so it leans and flies with the saucer, which keeps wandering and doing its job on its own (`Update` runs the AI while `Piloting`, only hover / click / bubble are skipped). The mouse always looks around (cursor locked while riding, `cockpitLookSpeed` 0.35), WASD walk (`walkSpeed`, kept within `walkRadius` and off the alien); Escape (`PixelWindows` 125) climbs out (no Leave button: the cursor is locked). The old piloting (flying it yourself, the console screen camera, abducting from the cockpit) was removed.
