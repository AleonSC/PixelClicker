## PixelUI.cs

"Inventory" toggle box (top-left) (**rows = swatch + plain light name + right-aligned amount** (Currency tab: swatch + number only by default, the name in the hover tip, click a row to switch all rows to name + number: `PixelUI.CurrencyShowNames`, PlayerPrefs `PixelClicker.Setting.InventoryNames`, `PixelClickable`) via `SetRow` / `RowParts`, 'Pixels' suffix stripped, ~95% opaque frame, ONE fixed height `maxPanelHeight` on every tab; infinite resources show an infinity sign via `PixelConsumables.OwnedText`) with Currency / Consumables tabs (Consumables has a half-width category dropdown with a search box beside it (`consumableSearchField`, `SetCategoryRowActive`; searching lists every held consumable whose name matches, ignoring the category); opening it closes the Log via `PixelUI.SetInventoryOpen` / `PixelLog.SetLogOpen` - they never show together) (right-click a potion to drink), active-potion timer and a tier guide ("Click X more Y pixels..." / "Y pixel unlocked") at top of screen; Currency tab: per-tier counts, cursor `+N` popups (manual) / cube popups (auto), vacuum `+X` total popup, per-entry vacuum `+X` indicators. Builds in `Start()` so shop-added tiers are included. The tier guide text ("Click X more...") stays hidden until the new-game intro tips have been closed (`PixelHints.IntroHoldsGuide`). The Inventory has a third **Materials** tab (`RefreshMaterials`): one line per `PixelMinigame` that overrides `MaterialName` / `MaterialAmount` / `MaterialColor` and has some (Stardust, Meteor Chunks, Bomb Parts, Ghost's **Ectoplasm** - 1-4 per caught ghost, `ectoplasmMin/Max`, saved via `ExtraValue`; no use yet, it is on the to-do). Tier lines auto-size down (no wrap) for huge numbers; the Log's rows do the same and `FitAmount` starts the amount box right after the name's text. **Simplified (pinned) Inventory:** a small toggle button at the window's top left (four-squares icon, green while on; it pins the tab you are on: `PixelUI.CompactMode` 1 = Currency, 2 = Consumables, PlayerPrefs `PixelClicker.Setting.InventoryCompact`, global) drops the title / X / tabs and shows only swatch + number rows (currency, or every consumable you hold as swatch + `xN`; a plain left click uses it, hover shows the name) in a box as wide as its widest line (`FitCompactWidth`: swatch + the text at full size, measured with a hidden label; a `compactWidth` typed in the Inspector overrides it) and as tall as its lines; it ignores Escape (it is not a registered window). **It is a movable window now** (like the Skills tracker): drag it anywhere (`PixelPopoutDrag` on the box; the list's ScrollRect is disabled while it doesn't scroll so the drag gets through), two small buttons stacked at its top right - minimise (-/+, only the button row stays) and stick (padlock, can't be dragged); position / minimised / stuck are global PlayerPrefs `PixelClicker.Inventory.CompactX/Y/Small/Stuck` (`UpdatePinnedPlacement`, `KeepCompactOnScreen`; the spot the player chose is kept as `compactDesired` and re-applied every frame before the on-screen clamp, so a window that was pushed up to fit when maximised returns to its spot when minimised again - the skill tracker does the same with `trackerDesired`); un-pinning puts the window back in its normal place. It no longer fades away when other windows open: it stays visible BENEATH them (its canvas sorts below the Shop / Log / Bank / Skills canvases; `SetInventoryOpen(false)` is ignored unless `force`; the Inventory dock button and the toggle still close it for good). The Inventory key still cycles currency <-> consumables before closing (`InventoryKeyCycle`).

## Inventory currency groups (PixelUI.Refresh, CurrencyGroup)

The Currency tab lists the pixel rows in GROUPS under foldable headers (click a header, '- PURE' / '+ PURE'; folded keys saved in PlayerPrefs `PixelClicker.Setting.InventoryFolded`, global): **Pure** = White..Blue (the base colours, the shop's money), **Composite: <Skill>** = a skill pack's goods (`PixelSkills.PackOfType`; Wood belongs to Woodcutting), one group per skill, **Exotic** = everything else (Glass, Mirror, Vacuum, Obsidian, Luminescent, Ghost, Meteor, Solar, Singularity, Dragon Cubes...). The Ultra row stays above all of them. The pinned (compact) Inventory shows the same order with no headers. Naming rule: 'Pure' is reserved for the base colours; there is no 'Raw' / 'Refined' ladder (refined results would be crafted items in Materials, not currency tiers).


The Consumables tab opens on its **Devices** sub-tab by default (`PixelUI.consumableSubTab` starts at 1).
