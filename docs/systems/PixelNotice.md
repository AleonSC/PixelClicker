## PixelNotice.cs

`PixelNotice.Show(message, seconds, onClosed, compact, small, aboveCombo, nearLog)` (`nearLog` = small box at the bottom left beside the event log, used by the `event_log` tip shown at the first tier unlock; `aboveCombo` = a small box at the bottom just above the combo meter, used for the first-combo tip) / `Hide()` (`small` = a narrow small-text box, used for the first-time minigame tips `minigame_<id>` and the first black hole): a one-off tip box (message + "Got it") at the top of the screen under the black bar; built lazily, one at a time; **Escape closes it like Got it and drops the queued tips** (`PixelWindows` priority 140, `PixelHints.ClearQueue`). Used for first-time hints (first black hole, `PixelHints`); `PixelNotice.IsShowing`. **Typewriter + back:** untimed boxes type their text out (`TypeCharsPerSecond` 80); the first Got it press completes the text, the second closes (`OnOk`). Optional `onBack` parameter of `Show` adds a small back arrow at the top left (hold 0.6 s via `PixelHoldButton`): it closes the box WITHOUT running `onClosed` and calls `onBack` (the shop and skills tutorials pass the previous step). Cubie's pages and the visitor greeting / aside boxes type the same way (visitors: `StartType` / `TickType` / `FinishType`), Cubie's panel and the aside box have a hold-to-go-back arrow (Cubie: one page back, the gift is only handed over once; aside: back to the greeting). `nearScreen` (a `Func<Vector2?>` screen point the small box follows, beside it) + `freezeTime` (`Time.timeScale` 0 until the box is closed, restored after): used by the first Ghost Hunt tip, which `PixelHints` shows with no auto-close. With `PixelShop.tipBoxMatchesShop` (default on) the big purchase / unlock tip boxes sit to the right of the open shop window (`PixelNotice.SideAnchor/SideWidth/SideGap`, set by `PixelShop.BuildPanel`: as tall as the shop, as wide as the currency panel, mirroring it on the left); with the shop closed they fall back to a centred shop-sized box. `beside` (a window's RectTransform, e.g. `PixelLog.WindowRect` / `PixelUI.WindowRect`) puts a 640-wide box just to the right of that window, top- or bottom-aligned (`besideBottom`); the new-game intro tips use it.

## Skip button
`PixelNotice.Show(..., onSkip)`: a small Skip button at the box's top right (hold 0.9 s; like the back arrow). It closes the box without running onClosed and calls onSkip. The Shop, Skills and Toggles tutorials pass an onSkip that jumps to their own end step (marks only that tutorial seen), so skipping one never skips another.
