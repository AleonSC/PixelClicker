# PixelDevTools

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelDevTools Changelog tab

**The Changelog moved from the pause menu to the Dev Tools panel** as a third tab (`BuildChangelogView` / `RebuildChangelog`, `changelogResource` 'Changelog', newest first); the right half of the tab row is shared by the To-Do and Changelog buttons. The pause menu's Changelog button / screen are no longer built (the old fields stay unused).

## PixelDevTools.cs

Dev tools (Editor/dev builds only unless **`allowInFullBuild`** is ticked on the component; removes itself otherwise): a glowing "divine" slide-out **Dev Tools button docked at the bottom-centre of the screen** (`BuildDockButton`, `PixelDevButtonFx`: pulsing golden halo, floating halo ring, sparkles; `PixelHud.Dock` now supports anchor x = 0.5 = centred; no longer in the pause menu) opens a panel (registered in `PixelWindows`, Escape closes it): pixel dropdown + amount field + Add, add-to-all (both also give the same number of Ultra pixels via `GiveAmount`, `alsoAddUltra`), minigame dropdown + Spawn (`PixelMinigame.SpawnNow`/`DisplayName`), "Skip intro" (`PixelShop.DevSkipIntro`: unlocks Gray + Black, buys the RGB pack and Auto Clicker free), Unlock all shop items (`PixelShop.DevUnlockAll`), tick box for Q = `PixelClicker.ClearOldPixels`, Close is an **X button at the top right** of the panel (no bottom Close button). **Layout (current):** pixel drop-down | amount field | green plus button (Add) | yellow paw button (Give pet: the selected pixel's pet, or every pet quietly for All pixels; there is no separate give-all button) - both drawn in code by `DevIcons` (`PlusSprite/PawSprite/FileSprite`); 'Skip intro', 'Give next Dragon Cube', 'Unlock all shop items', 'Reset all counts to 0'; a file-icon button at the TOP LEFT of the panel opens the crash report folder; the god mode row reads 'God Pixel Mode' with its controls as a hover tooltip (`AddTip` / `PixelDevTip`, `PixelHoverTip`). The panel uses `PixelUIKit.StyleWindow` like every window. Input row **"Clicks per click"** (`clickCount`, PlayerPrefs `PixelClicker.Dev.ClickCount`, synced per save): sets static `PixelClicker.DevClickCount` N - one click counts as N clicks everywhere: payout x N (on top of any multiplier), tough pixels take N hits per click (extra hits carry over), `timesCollected` += breaks, and the combo grows by N (`PixelCombo.AddClick`). tick box "Infinite resources" (`PixelClicker.InfiniteResources`: `TrySpend`/`CanAfford`/Ultra boosts cost nothing, and consumables are unlimited too: `PixelConsumables.ItemOwned` reports 99999 of every item, using / placing / planting / crafting never decrements and the shop never says Full; **the Pixel Bank too**: it never fills up (`TakeIntoBank` skips the capacity check, window shows 'Stored: N / Infinite'), spitting never lowers the stored counts and area suction runs 10x faster; the hose can spit every unlocked ordinary pixel type even if none is stored - `PixelBank.Has` - paying `RollOldPixelAmount`, and the nozzle plate shows an infinity sign). Dev tool settings (tick boxes, amount, drop-down choices) are remembered in PlayerPrefs (`PixelClicker.Dev.*`, `rememberSettings`). The pixel drop-down's first entry is "All pixels" (replaces the old add-to-all button). "Skip intro" / "Unlock all" leave everything with a Toggles switch (auto clicker, grabbing, time stop, combo, minigames, spawn switches) unlocked but OFF. Tick box "Disable old pixel despawns" (`OldPixelDespawn.DevNoDespawn`). Tick box "Disable old pixel limit" (`disableOldPixelLimit`, PlayerPrefs `PixelClicker.Dev.NoLimit`, `PixelClicker.DevNoOldPixelLimit`: `CopyCap` returns 0 = no cap on how many old pixels lie around, the Old Pixel Capacity upgrade is ignored). Tick box "God pixel mode" (`PixelClicker.GodMode` blocks cube clicks / grabbing / device removal): small display next to the cursor, scroll = pick a pixel, left = `SpawnStoredPixel` at the cursor, right = destroy old pixels near it. Tick box "On-screen spawn selector" (`spawnSelectorEnabled`; also holds the minigame drop-down + Spawn button): a drop-down row at the top of the screen (with the minigame drop-down + Spawn + **Despawn** buttons; Despawn = `PixelMinigame.DespawnNow`) (normal / Monochrome pack = White+Gray+Black / RGB pack = Red+Green+Blue / every pixel type incl. locked ones) that calls `PixelClicker.SetDevSpawnTiers` so only those types spawn. **Middle-click swap**: a third drop-down at the end of the on-screen selector row ('Middle click: <pixel>', every type incl. locked, `swapDropdown`, PlayerPrefs `PixelClicker.Dev.SelSwap`); with the selector on, a middle click (`PixelInput.MiddlePressed`, not over UI) calls `PixelClicker.DevSwapCurrentPixel(type)` which replaces the pixel on the cube at once (`devSwapped` keeps even a locked type until it is clicked; the next pixel rolls normally). Uses `PixelUIKit.CreateDropdown/CreateInputField`. Escape closes the panel first. The on-screen spawn selector fades out after `selectorHideSeconds` without use and the Dev Tools dock button after the longer `dockHideSeconds` (`PixelFadeOnIdle`: a CanvasGroup that returns when the mouse is over the row / near the dock spot, a drop-down is open or the panel is open; faded UI can't be clicked). The window is capped at `panelHeightLimit` (760): the pixel dropdown row, the tabs and the Close button stay fixed and the other rows scroll (a drop-down can't live inside a scroll list). **To-Do tab** (Tools | To-Do buttons at the top of the panel; `BuildTodoView`, `RebuildTodo`, `todoResource` = `Assets/Resources/Todo.txt`): a scrolling list of that file's lines (`[ ] open`, `[x] done`, `# Heading`, `//` hidden note). Button "Reset all counts to 0" (second click confirms; `PixelClicker.ResetAllCounts` + `PixelBank.SetState(null)`): zeroes every pixel count, Log lifetime total and click count and the Bank, keeps unlocks, Ultra pixels, shop packs and achievements.

**Keys and the dock button (current).** The Dev Tools window opens / closes with `PixelAction.DevTools` (default F9, rebindable in Settings > Key bindings; the three dev keys are hidden outside the Editor / development builds). **The glowing dock button and its tick box were REMOVED** (the Dev Hub window made them obsolete; so were `PixelDevButtonFx` / `PixelFadeOnIdle` and the "Skip intro" button / `PixelShop.DevSkipIntro`). The old **"Unlock All"** button is gone: the **Unlock** widget's 'All shop items' does `PixelShop.DevUnlockAll` (every shop item and ordinary pixel type, switchable things left off) and the **Max XP** widget fills skills (see "Unlock and Max XP widgets"). `PixelAction.MarkMoment` (F10) and `PixelAction.InspectHover` (F11) call `PixelDevProbe.MarkMoment()` / `Inspect()` at once (screenshot + state report; what is under the mouse). Tools buttons 'Snapshot bounds', 'Mark this moment' and 'UI layout dump' wait `boundsSnapshotDelay` seconds first (so the panel can be closed). Reports land in `<persistentDataPath>/Snapshots` and on the clipboard (`PixelDevProbe.Save`). **Mock up mode** (one tick box) = `PixelDevMockWindow`: one draggable window with a Shapes tab (`PixelDevShapes`) and a UI pieces tab (`PixelDevMockup`) and a minimize button that leaves a thin header; replaces the two separate 'Shape placer' / 'UI mockup builder' tick boxes (old `ShapesOn` / `MockupOn` prefs are ignored).


## PixelDevInspector.cs

Tools tab tick box 'Inspector' opens a draggable, minimizable window (header notes in `PixelDevInspector.cs`): World tab (time scale, fixed step, gravity / Gravity Y, solver iterations, thresholds, live counts, a drop-down of every game system) and Selected tab (Pick mode = click any collider, Parent / Active / Destroy, filter, foldable components; game scripts list every supported field by reflection, Unity components a fixed list; old pixels also show their PixelTier). 'Copy edits' copies every change as `Owner.field = value` lines.

## Dev Tools window (PixelWindowChrome)

The Dev Tools panel is no longer a modal dialog: no dimmer, so the game stays clickable. `PixelWindowChrome` (header notes in the script) gives it drag by the title (kept between the black bars), Minimize ('-'), and docking to the left / right edge (drag against a side; slides out on hover or while typing; undock arrow). Prefs `PixelClicker.Dev.Window.*`. My Window, the Mock up window and the Inspector still have their own copies of this logic.


## Dev Hub (PixelDevHub.cs) - replaces the Dev Tools panel, the Inspector window and the Mock up window

One window for every dev tool: drag, minimize, dock to a screen side (`PixelWindowChrome`), filing-cabinet tabs (Main, To-Do, Changelog, Inspector, Shapes, UI Mock) that can be reordered by dragging and popped out into floating windows (drag a tab down; 'Dock' button or dropping the window on the hub puts it back). The Main tab is `PixelDevTools`' rows as WIDGETS: every row is a card with a grip (`PixelWidgetBoard`, order saved as `PixelClicker.Dev.WidgetOrder`). The 'Inspector' and 'Mock up mode' tick boxes are gone (they are tabs now). Tools get their content with `PixelDevHub.TabRoot(id)` and `PixelDevHub.SetTabCallback(id, visible => ...)`; `PixelDevMockWindow` is only a doorway to the hub's tab roots. The Inspector applies an edited value while you type and again on Enter, reads it back and reports the result in its status line (so a value the game overwrites is visible).


## Hub tabs: icons, Docs, Notes

Hub tabs are small: each shows only a pixel-art icon, the active tab also shows its name (`PixelDevHub.LayoutTabs`, icons drawn from text in `TabIcon`). Tabs now: Main, Docs, Inspector, Shapes, UI Mock. **Docs** (`PixelDevDocs.cs`) has three permanent sub-tabs: To-Do, Changelog and **Notes** (your own notes typed in-game: list on the left, title + multi-line text on the right, auto-saved to `<persistentDataPath>/DevNotes.json`, Delete confirms with a second click). `PixelInputCaret` draws the text cursor in the Inspector / Notes fields.


## Spawn widgets (replaced the on-screen spawn selector)

The 'On-screen spawn selector' tick box and the row at the top of the screen are gone. The Main tab now has a PINNED widget board above the scrolling one (its own saved order, `PixelClicker.Dev.PinnedOrder`; pinned because a drop-down's list would be clipped inside a scroll view): **Add pixels** (the old pixel drop-down | amount | Add | Give pet row), **Spawned pixel** (drop-down: normal / Monochrome / RGB / every pixel; **Spawn** = only that pixel spawns (`SetDevSpawnTiers`) and a single exact pixel replaces the one on the cube now, the button is green while active; **Despawn** = back to normal), **Minigames** (drop-down, **Spawn** = `SpawnNow`, **Despawn** = `DespawnNow` of the chosen one or every busy one) and **Middle click** (drop-down, first entry 'off': a middle click swaps the pixel on the cube, `DevSwapCurrentPixel`). Built by `PixelDevTools.BuildSpawnWidgets`; saved: `Selector` (override active), `SelPixel`, `SelMinigame`, `SelSwap`.


## Feature Tester tab + Wood Chipper

The hub's **Tester** tab (`PixelFeatureTester.cs`) lists things that are not in the game yet as cards with Place / Clear. Place = a see-through ghost follows the mouse over the floor, left click puts a real one down (keeps placing), Q / E turn it, right click / Esc stops; placed test objects are not saved. Add a feature = one `Register(...)` line in `PixelFeatureTester.Awake`. First feature: **Wood Chipper** (`PixelWoodChipper.cs`): a detailed machine built from primitives (trailer, tyres, hopper, rollers, chute, engine, controls, beacon...) that pulls old pixels in and shreds them (`PixelClicker.ClaimOldPixel`, no payout) with chips, shaking, blinking beacon and exhaust smoke.


**Wood Chipper rules:** a wood pixel (`PixelClicker.IsWoodBlock`) gives Woodcutting XP (`woodXp`, 3, via `PixelSkills.AddXp` with the usual popup); any other pixel does `damagePerOtherPixel` (14) of `maxHealth` (100): the paint darkens, sparks fly, the exhaust gets thicker and blacker, a health bar floats over it; at 0 it is broken for good (stops, no beacon, 'BROKEN' label) and has to be cleared and replaced.

## Hub resize, widget headers
- The Dev Hub window has a grip in its bottom-right corner (`PixelWindowChrome.EnableResize`): dragging it SCALES the whole hub (0.55x - 1.6x, remembered as `PixelClicker.Dev.Hub.Window.Scale`). It is a scale, not a re-layout: the tabs keep the layout they were built with. A real re-layout would need every tab to build against a variable size.
- Every widget card (`PixelWidgetBoard`) has a header strip with its title and a '-' button: it folds the card up to just the header (hidden controls are restored on '+'); remembered per board (`<board prefKey>.Min`). The pinned cards at the top push the scrolling list down / up as they fold.
- Button labels inside widgets shrink to fit (`PixelUIKit.FitOneLine`), so long labels like DESPAWN no longer spill out of their button.

## One widget board, favorites
- The Main tab is ONE scrolling `PixelWidgetBoard` (saved order key `Dev.WidgetOrder2`): the old fixed "pinned" top half is gone. Drag a card by its whole header strip (title bar, easy to hit); the small grip icon is part of it.
- HOLD the right button on a card (0.7 s, a ring fills round the cursor, `PixelWidgetBoardDriver` -> `PixelHold`) to make it a FAVORITE: it snaps to the top, is tinted gold, and stays above the non-favorites (`Partition`); hold again to let it go back to the top of the others. Saved as `<board key>.Fav`.
- Drop-downs inside the scrolling board: `PixelUIKit.LetListEscapeMasks` moves an opened list to the root canvas so the scroll view's mask cannot clip it (untested in Unity: if a list still looks cut off, this is the place).

## Search bar, custom text, docked drag
- The Dev Hub header has a SEARCH field (`PixelDevHub.BuildSearch` / `RegisterSearch(label, tabId, reveal, keywords)`): it finds tabs, Main-tab widgets (`PixelWidgetBoard.SearchTab` registers every card) and tester features; picking a result (or Enter for the first) opens its tab, unfolds / scrolls to the card (`PixelUIKit.ScrollTo`) and flashes it. Other tabs (Docs, Inspector...) are not searched inside.
- RIGHT CLICK any label in the hub (a quick click; a hold is the widget favorite) to type your own text (`PixelDevTextEdit`: Save / Reset / Cancel). Labels are found by hierarchy path; edits live in PlayerPrefs `PixelClicker.Dev.CustomText` and are stored per save profile by `PixelSettingsSync`. Drop-down captions, typed text and search results are left alone.
- Docked windows (`PixelWindowChrome`, My Window) can be dragged off the edge by their header: the drag undocks them (`PixelPopoutDrag.onBegin`).
- A 'Collapse all' button above the Main tab's widgets folds every card up to its header (it reads 'Expand all' while everything is folded; PixelWidgetBoard.SetAllMinimized).

## Unlock and Max XP widgets

Main tab widget **Unlock** (`shopunlock`): a drop-down with 'All shop items' and then every shop pack (marked `[not in shop]` for `hideInShop` packs and `(unlocked)` / `(level n)` for owned ones), an **Unlock** button (free, as if bought; upgrades go to their top level) and a **Relock** button (takes the pack back, locks its reward pixels, upgrades to level 0). 'All shop items' + Unlock = `PixelShop.DevUnlockAll` (every pack AND every ordinary pixel type, switchable things left off; it no longer touches skills); + Relock = every pack relocked. The old separate **Unlock everything** button is gone. Main tab widget **Max XP** (`maxxp`): a drop-down with 'All skills' and then every skill with its level, a **Max XP** button (that skill / every skill, Standard included, to its level cap: `PixelSkills.DevSetSkillXp(pack, true)`) and **Reset XP** (back to level 1). Texts `shopUnlockText`, `shopRelockText`, `shopAllText`, `maxXpText`, `resetXpText`, `allSkillsText`; the shop pick is remembered (`SelShopPack`).

## Super Rares widget

Main tab widget **Super Rares** (`superrares`) replaced the three separate 'Give next Dragon Cube', 'Give next God Cube' and 'Play next God show' widgets: a drop-down of every rare collectible tier in the game's order (the seven Dragon Cubes, the three God Cubes, the six Prime Cubes, the Prime Cubelette, the Golden Snitch; `(held)` marks ones you have), a **Spawn** button that puts the picked one on the clicker cube in place of the current block (`PixelClicker.DevSwapCurrentPixel`; click it to collect it like a real find, the God / Prime shows play then; the Golden Snitch waits for your click and flies) and a **Gauntlet** button that adds one Prime Gauntlet (`DeviceKind.Gauntlet`) to the inventory. A second row holds the "Farmer always has dragon seeds" tick box (moved here from its own widget; `PixelFarmerMinigame.DevAlwaysDragonSeeds`). Widget cards can now have several rows (`Widget(..., rows)`, `WidgetRowGap`). Texts `spawnRareText`, `giveGauntletText`; the pick is remembered (`SelRare`). Every remembered Dev Tools choice is kept PER SAVE: the keys are listed once in `PixelDevTools.IntPrefs` / `StringPrefs` and declared with `PixelPrefs.DeclarePerSave`; a new remembered choice goes in that list.
