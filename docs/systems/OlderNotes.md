- **Lessons kept from that handoff:**
  - Patching by "first text match" put code in the wrong function twice: when editing with scripts, assert the match is unique or anchor on the function name, then `grep -n` the result.
  - `Time.timeScale = 0` is used by the pause menu, Time Stop and the title screen: anything that must run while frozen uses `Time.unscaledDeltaTime`.
  - A fresh UI element's `rect` is not valid until the canvas updates: compute sizes from `Screen` / the canvas scale instead.

- **Fishing rework:** Water (the Farming pixel) is Fishing's filler (very common: `fillerStartShare` 0.75 -> 0.5) and replaces Driftwood (retired, `LeftOutOfSpawns`); the pack's types are Fish, Seaweed, Shell, Pearl, Water, Jellyfish (`packDataVersion` 21). A block can belong to several packs (`PackForTier` / `LeftOutOfSpawns` prefer the pack in play). **Fish** is rare (weight 0.15, 1 click, pays 12): its click (manual only, the auto clicker waits) calls `PixelWeakspotMinigame.TryStartFishing(done)` (a Weak Spots round with the fish still on the cube); `PixelClicker.FishingDone(caught)` then pays it through a normal click (`fishingPass`) or says 'The fish got away!' and rolls the next pixel. If the round can't start (minigame switched off, another minigame busy...) the click just catches the fish.
- **Fishing, part 2:** the **Jellyfish** is electric now (9 clicks; `PixelLook.lightning` look, `PixelElectricFx` Hit / Break cases, sounds `pixel_jellyfish` / `jelly_sting` = `PixelSynth.Zap` / `Charge`; when it goes off in `TriggerHazard` it stings `jellyfishBlastFactor` (1.5) x wider, fires a big `FractureFx` and fries every bait pellet). **Bait** (`PixelType.Bait` 72, in the Angler's Pack, `packDataVersion` 22, `looksVersion` 47): collecting one calls `PixelBait.Drop` (PixelBait.cs: `baitPellets` 6 small spheres hop out round the cube onto the floor, on screen, max `baitMaxPellets` 24, rot after `baitLifetime` 60 s); `PixelBait.FishMultiplier` (1 + pellets x `baitPerPellet` 0.35) multiplies a Fish block's spawn weight in `SpawnWeightOf`; `PixelBait.DestroyAll(zap)` removes them. **Fish without the minigame:** when `PixelWeakspotMinigame.FishingAvailable` is false (switched off in Toggles) a fish takes a random 7-25 clicks (`fishNeed` / `fishReel`, manual or auto), the last one pays; with it on, only a manual click starts the round.
- **Simple save flow (main menu):** nothing loads by itself while the title screen shows (`PixelSaveGame.Start` skips the startup load when `PixelTitleScreen.Showing`). The big main button reads **Continue** when there are saves and none has been loaded / written this run (`PixelSaveGame.HasLoadedSave`): pressing it loads the most recent file (`TryGetMostRecentSlot` by write time, `ContinueMostRecent`, pays the time away) and plays; **New Game** when there are no saves at all; **Play** once a save was loaded / written (e.g. after Quit > Main menu: just resumes). The floppy icon opens the slot window: a filled slot loads, and from the title an EMPTY slot turns the Load button into **New Game** (`PixelTitleScreen.StartNewGame(slot)`: sets the slot (`UseSlotForNewGame`) and plays; if the game was already played this run (`PlayedOnce`) it sets `PixelSaveGame.AutoStartNewGame`, resets tips / achievements and reloads the scene, and the title then presses Play by itself). Autosave / quit-save always write into `CurrentSlot` (the slot loaded or chosen for the new game).

## Profiling (added with optimization step 2)
Profiler markers (Window > Analysis > Profiler, CPU > Timeline / Hierarchy, search "Pixel."): `Pixel.FloorRedraw` (animated floor texture), `Pixel.ElectricLinks.Scan`, `Pixel.SolarClusters`, `Pixel.QuantumScan`. Reading the code, the husk scans are timer-limited (0.1-0.15 s) and O(n) with early exits, and `GetComponent<OldPixelInfo>` only appears in timer-driven scans (`PixelViewBounds` already caches it), so a shared pixel registry / pooling is NOT worth doing until a profile with ~150 husks shows these markers (or the per-object Update / FixedUpdate of `OldPixelDespawn` / `ScaledGravity`) taking real time.

- **Click lag (Editor):** per-click click-effect bursts are pooled (`PixelBasicFx` Burst pool + `PixelFx.Configure`), the spawn path reuses one MaterialPropertyBlock and caches the live cube's colliders, and Profiler markers `Pixel.SpawnFallingCopy`, `Pixel.Materialize`, `Pixel.ClickFx` show what is left. Still unpooled: the husk GameObjects themselves (about a dozen components each), `PixelFarmFx` / `PixelElectricFx` bursts, +N popups. Profile before pooling more.
- **Pixel rules (value / body / use):** a click gives a block's currency and drops its husk (material, never currency); holding a utility block gives charges. Design in `docs/systems/PixelRules.md`; Vacuum, Pixel Bank and the Solar trickle need a new job under it.
