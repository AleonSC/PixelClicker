## PixelPetsCustomize.cs

Part of `partial class PixelPets`: **names and outfits**. Hovering a pet shows a **name tag** above it (`UpdateTag`, `EnsureTag`: screen-space canvas, the pet's name + a procedurally drawn pencil button; stays `tagGraceSeconds` after the mouse leaves and while the mouse is over it, and the pet stands still while its tag is up). The pencil opens the **customization window** (`OpenCustomize`; freezes the game like the found popup via `PopupOpen`, Escape closes it through `PixelWindows` priority 160): a name box (`maxNameLength`, empty = default "{Pixel} Pet"; `Pet.customName`), a **3D view** (a hidden preview studio far below the scene `StudioHeight` with a camera rendering into a `RenderTexture` shown by a `RawImage`; click-drag turns the model via an `EventTrigger`, it spins by itself otherwise; no extra light - it uses the scene's directional light) and `<` `>` arrows that change the **outfit** (`Pet.outfit`, applied to the live pet at once by `ApplyOutfit`). **Outfits** (`OutfitList`) are generated from `outfitSeed` (`outfitCount` = 12 + "Plain"), followed by the **named special outfits** (`Specials()`: Super Saiyan / Blue / God / Ultra Instinct / Legendary Spikes (`Acc.SuperSaiyanHair` = a cone-spike mane + `Acc.Aura` = see-through spheres and flames), Pirate Captain, Viking, Chef, Kitty, Bunny, Santa, Flower Child, Gentleman, Explorer, Punk; new accessories are appended to the `Acc` enum so saved outfit numbers don't change): 2-3 of four slots (head / face / neck / back) each with one accessory (`Acc`: Top Hat, Party Hat, Wizard Hat, Crown, Halo, Headphones, Antennae, Bandana, Sunglasses, Mustache, Bow Tie, Scarf, Cape, Wings) in palette colours, built from primitives + a runtime cone mesh in unit-cube space under an "Outfit" child (`BuildOutfit`, colliders removed) so most of the pet stays visible. Name and outfit are saved in `PixelPets.Export` (`type:off:outfit:escapedName`; older saves still load) and used by the Toggles Pets tab and the Stats Pets rows (`NameOf`).
