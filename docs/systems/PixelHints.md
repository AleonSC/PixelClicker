# PixelHints

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelHints.cs

First-time tips: Inspector list of `Hint` (id, enabled, text; defaults added by `EnsureDefaultHints`), shown once each via `PixelNotice` (remembered in PlayerPrefs `PixelClicker.Hint.<id>`, queued one after another, `showDelay`, master `hintsEnabled`). `PixelHints.Trigger(id)`; hooks events itself (potion drunk, device placed `device_<kind>`, crafted, first combo, minigame spawned `minigame_<id>`, `PixelClicker.UltraGained`); `PixelShop.TryBuy` triggers `crafting`/`grab`/`timestop`/`bank`, `upgrade_interval/clicks/combo/bank`, `upgrade_ultra` (Ultra boost) and `pixel_<Type>` for packs that unlock pixel types. The `event_log` intro tip is NOT queued as a box: `Enqueue` only announces it as a log line (`ShortFor` text) whose click opens the tip (`ShowEventLogTip` on tutorial replay does the same). Also owns the **event log**: a transparent box at the bottom left running from above the bottom black bar up to the top black bar (`overlayWidth`), newest line at the bottom (`PixelHints.Announce(short, fullText)`); lines in the upper part fade out towards the top (`fadeUpperLines`, `fadeStartFraction` 0.5, `fadeTopAlpha`; per-row CanvasGroup set in `UpdateRowFade`, called from `ApplyScroll`, so it follows scrolling); **a new event shows only the newest line** (`fullView` false: `RebuildRows` builds one row) and the **whole list only when the player opens the log** (the EventLog key: `DisplayOverlay(true)`; pressing it while only the newest line shows opens the full list, pressing it again hides it); the whole box fades after `overlayVisibleSeconds` unless the mouse is over it; **mouse wheel** over it scrolls; left-click a line to show its full tip, **Enter** shows the box when hidden and fades it away when open, **right-click** anywhere also fades it away (`logWidth`, `logFontSize`); the log (`historyMax`) is saved with the save file (`SaveData.eventTexts/eventFulls`, `ExportHistory/ImportHistory`) and `SuppressFor` mutes events while a save loads; each `Hint` has a `shortText`; also announces new pixel types via `onTierUnlocked`, the auto clicker and the first black hole; ignored for `startupQuietSeconds` after start). Every shop purchase / upgrade level / Ultra boost (not Value upgrades: too frequent) also announces itself on the event line (`PixelShop.AnnouncePurchase`; first-time tips replace it with their own line). The `device_Sorter` tip is a small box that freezes time until 'Got it' (`freezeTime`). Extra bank/Time Stop tips: `bank_hose/_suck/_spit/_full`, `timestop_first/_empty`. Also runs the **new-game intro** (after the title screen; marked seen only once both tips were confirmed): once, on a fresh game, opens the Log with a tip, then (after "Got it") the Inventory with a tip, then a third tip on how currency is earned (`introEarnText`: clicking is the main way, upgrades / minigames / old pixel management open other ways); the tier guide appears after that (`showIntro`, `introLogText`, `introInventoryText`, `introEarnText`; uses `PixelNotice.Show(..., onClosed)`). Added by `PixelClicker.Awake`.

**Intro tip 4 (right click):** the new-game intro now has a fourth Got-it box right after the one about clicking (`introRightClickText`): the right mouse button (hold a block, Block Hold + its stake). Showing it marks the `stake_intro` tip as seen; saves that already finished the intro get `stake_intro` once after 25 manual clicks instead (`PixelBlockHold`).

**Intro fixes (2026-10-16):** the cube cannot be clicked while the new-game intro is pending or running (`PixelClicker.ExternalClickBlock` includes `PixelHints.IntroHoldsGuide`), so the tier guide and clicking start after the last box; a game counts as new while fewer than `introFreshClicks` (60) pixels were collected, so a few early clicks never skip the intro; tip 4 (right click) only shows when Block Hold is unlocked (Standard tree) - otherwise `stake_intro` stays unseen and shows later via PixelBlockHold.
