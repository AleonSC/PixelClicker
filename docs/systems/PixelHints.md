# PixelHints

Moved from CLAUDE.md. The script header comments and `CLAUDE.md` index point here.

## PixelHints.cs

First-time tips: Inspector list of `Hint` (id, enabled, text; defaults added by `EnsureDefaultHints`), shown once each via `PixelNotice` (remembered in PlayerPrefs `PixelClicker.Hint.<id>`, queued one after another, `showDelay`, master `hintsEnabled`). `PixelHints.Trigger(id)`; hooks events itself (potion drunk, device placed `device_<kind>`, crafted, first combo, minigame spawned `minigame_<id>`, `PixelClicker.UltraGained`); `PixelShop.TryBuy` triggers `crafting`/`grab`/`timestop`/`bank`, `upgrade_interval/clicks/combo/bank`, `upgrade_ultra` (Ultra boost) and `pixel_<Type>` for packs that unlock pixel types. The `event_log` intro tip is NOT queued as a box: `Enqueue` only announces it as a log line (`ShortFor` text) whose click opens the tip (`ShowEventLogTip` on tutorial replay does the same). Also owns the **event log lines** (`PixelHints.Announce(short, fullText)`; since 2026-10-25 they show only in the **Log window's Event log tab**, `PixelLogEvents.cs` - the on-screen box at the bottom left (overlay, fade, scroll, Settings > Interface > Event log switch) and the Pocket's Event log tab are gone; the event log key opens / closes the Log on that tab, `UpdateLogKey`; Settings > Accessibility > Event log size still scales the lines); the log (`historyMax`) is saved with the save file (its own save part `eventLog` via `PixelSaveRegistry`, `ExportHistory/ImportHistory`) and `SuppressFor` mutes events while a save loads; each `Hint` has a `shortText`; also announces new pixel types via `onTierUnlocked`, the auto clicker and the first black hole; ignored for `startupQuietSeconds` after start). Every shop purchase / upgrade level / Ultra boost (not Value upgrades: too frequent) also announces itself on the event line (`PixelShop.AnnouncePurchase`; first-time tips replace it with their own line). Extra bank/Time Stop tips: `bank_hose/_suck/_spit/_full`, `timestop_first/_empty`. Also runs the **new-game intro** (after the title screen; marked seen only once both tips were confirmed): once, on a fresh game, opens the Log with ONE tip (`introLogMessage`: click to earn pixels, the goals are in the Log; since 2026-10-24 - it used to be three boxes: Log, Inventory, how to earn), plus the right-click tip only once Block Hold is unlocked; the tier guide appears after that. The Inventory tip (`introInventoryText`) comes later, once, right after Cubie's first visit hands over the Recycler: `PixelHints.ShowInventoryIntro` opens the Inventory on Consumables (`PixelUI.ShowInventoryTab`) and leaves it open so the Recycler can be placed (seen key `intro_inventory`). Added by `PixelClicker.Awake`.

**Intro tip 4 (right click):** the new-game intro now has a fourth Got-it box right after the one about clicking (`introRightClickText`): the right mouse button (hold a block, Block Hold + its stake). Showing it marks the `stake_intro` tip as seen; saves that already finished the intro get `stake_intro` once after 25 manual clicks instead (`PixelBlockHold`).

**Intro fixes (2026-10-16):** the cube cannot be clicked while the new-game intro is pending or running (`PixelClicker.ExternalClickBlock` includes `PixelHints.IntroHoldsGuide`), so the tier guide and clicking start after the last box; a game counts as new while fewer than `introFreshClicks` (60) pixels were collected, so a few early clicks never skip the intro; tip 4 (right click) only shows when Block Hold is unlocked (Standard tree) - otherwise `stake_intro` stays unseen and shows later via PixelBlockHold.

**New game decided at Play (2026-10-16):** `PixelTitleScreen.NewGameStarted` is set in OnPlay (true when nothing was loaded). The intro plays and clicks stay blocked from Play until its last box whenever it is true, whatever the player clicked or which tips were seen in earlier games; the old 'nothing collected' check is only the fallback when there is no title screen.
