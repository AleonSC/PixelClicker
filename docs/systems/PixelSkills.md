# PixelSkills

## PixelSkills.cs / PixelSkillsWindow.cs

**Skill system SHELL** (added by `PixelClicker.Awake`, `PixelSkills.Instance`, `disableSkills`): skill packs swap the basic cubes (monochrome, RGB, Glass, Luminescent) for another set and you train the skill of the pack in play. `SkillPack` list (id, name, description, accent, replaces / spawns / xpFrom texts, `baseXp` + `xpGrowth`, `Perk` list with `implemented` flag; built-ins **Standard** and **Mining** are added by id in `EnsureDefaults`). **Mining IS Prospector mode** (`ActiveId` reads `PixelProspector.Setting`, `SetActive` writes it; the change applies from the next spawn, the current cube stays), the Skills window is the only place that chooses it; the old Toggles 'Mining mode' switch is gone; a pack is available when its pixels are unlocked (`IsAvailable`). XP = stat counter `skill.<id>.xp` (saved generically, `Xp`, `LevelOf(pack, out into, out need)`); `OnCollected` adds 1 XP per manual / `autoXpFactor` (0.25) per auto click of the active pack's pixels (every pack's baseXp is multiplied by `xpCurveScale` (2) - `BaseXpOf`, used by LevelOf, Mastery and the balance report - so Standard's 380 means level 2 after 760 blocks; Standard is different: every collected block gives it a flat `standardXpPerBlock` 1 XP, manual or auto, whatever skill is trained, no multipliers - `AddXpFlat`); a level-up posts an event-log line. **Window** (`PixelSkillsWindow.cs`): a docked **Skills tab on the left edge directly under the Bank + Hose pair** (`PixelHud.DockInGroup`, width `PixelBank.DockGroupWidth`, appears when `SkillsTabUnlocked`: a skill pack is owned, or Standard is level 2 and its level-2 popup - which opens the window - is no longer waiting; Cubie no longer introduces skills: the Toggles tutorial lost its skills step and the skills walk-through only auto-starts with `autoStartTutorial`, off), a window that opens from the left edge like the Bank window (closes / is closed by the Inventory, Log and Bank, `CloseWindowIfOpen`; `PixelWindows` priority 14, `PixelPop`): header (training line + XP bar), pack cards on the left (Standard is a card, locked packs show ???), the selected pack's detail + perk list + Train button on the right; the first availability auto-opens it with a one-off explanation (`introText`, tip id `skills_intro`). **Pixel packs are generic now:** `SkillPack.types` lists a pack's pixel types (the FIRST one being unlocked = the pack is available), `PixelSkills.PackSetting` (PlayerPrefs `PixelClicker.Setting.SkillPack`, per save; old Prospector = Mining) is the one chosen pack, `PixelProspector.Setting` just reads / writes it, and `PixelSkills.LeftOutOfSpawns(type)` (used by `PickSpawnTier`) keeps a pack's pixels out of the spawns unless the pack is in play OR the type is a **guest**; the basic pixels step aside while any pack is in play. **Guests** (cross-breeding): a `TreeNode.guestType` node, once bought, makes that block a switch in Toggles > Pixels ('Seed (Farming)'; `UnlockedGuests`, `GuestOn`, `SetGuest`, PlayerPrefs `PixelClicker.Setting.SkillGuests`) so it also spawns in other rotations. (The Toggles window no longer has '<Pack> mode' switches: the Skills window is the only place that chooses the pack.) **Farming** (id `farming`, bought with the Farmer's Pack): see the `PixelFarmPixels` note below. **Electrician** (id `electrician`, `PixelSkills.ElectricianId`, bought as the shop's **Electrician's Pack** - a `ShopPack` with `skillId` = 'electrician', needs the Auto Clicker, 8K each Red / Green / Blue, listed under Skill packs; `PixelShop.IsSkillPackBought`; **the separate Electric Pixel pack is gone** - Electric is the pack's first pixel, no longer a spawn toggle (`IsSpecialType` lost Electric), and `MigrateOldPackData` removes a saved Electric pack, upgrades a saved Electrician pack and makes the Mirror pixel need it): its eight pixels are Electric plus the pack's own **Resistor** (45, 2 clicks, pays 5, weight 0.6, a conductor), **Transistor** (46, pays 5; its click makes the NEXT collected pixel pay `transistorMultiplier` (2) x), **Fuse** (47, pays 5; x`fuseBonus` (3) if collected within `fuseSeconds` (3) of appearing, 0.3x after) and **Bulb** (48, pays 6; x(1 + `bulbPerConductor` (0.1) x old conductor pixels, max 30, `CountConductors`)), `looksVersion` 33, and **Wire** (`PixelType.Wire` 42, 1 click, pays 2, weight 1.0, copper), **Battery** (43, 3 clicks, pays 12, weight 0.4, green) and **Capacitor** (44, pays 6, weight 0.35, blue) - all `IsStandalone`; they spawn only while the Electrician pack is in play or as guests (tree node 'Static charge' covers Electric); Electric / Wire / Battery / Resistor old pixels carry the device links (`PixelClicker.IsConductorType`, `PixelElectricLinks.IsConductor`), a Battery click sets off an Overcharge too, and a Capacitor pays 1 + stored charge x `capacitorPayPerCharge` (0.15; every other click stores one charge, cap `capacitorChargeCap` 40, `PixelClicker.CapacitorCharge`) then resets; `looksVersion` 32; `CheckFarmBundle` also unlocks all of them once the pack is bought, `MigrateOldPackData` gives an older saved pack its pixels; XP from clicks of any of them; its other perks / nodes (Overcharge+, Wired up, Power bank, Surge) are 'coming soon'. **Offline Progression skill** (id `offline`, `PixelSkills.OfflineId`, available once the Auto Clicker runs): choose it, then choose which pack's pixels to play with (`SetPixelPack`, buttons in the detail panel); `PixelSkills.OfflineMode` (PlayerPrefs `PixelClicker.Setting.SkillOffline`, per save) makes `TrainingId` the offline skill and `OnCollected` gives EVERY click's XP to it only (no XP for the pack in play); `ActiveId` is still the pixel pack. Its effects are NOT built yet (perks and tree nodes say 'coming soon'). **Skill tree** per skill (`SkillPack.nodes` = `TreeNode` id / name / description / `requires` / `row` / `cost` / `implemented`, defaults by `DefaultNodes` for Mining, Offline and **Standard** (Standard's tree: first point on Block Hold or Power Click, which are locked until then; branches Lucky stake -> High roller and Quick charge -> Aftershock; `HasStandardNode`), also filled into older serialized packs): one point per level above 1 (`PointsAvailable` = level - 1 - spent), unlocked nodes are the counters `skill.<pack>.node.<id>` (`NodeUnlocked`, `CanUnlock`, `UnlockNode`); the detail panel's 'Skill tree' button opens a separate **skill tree window** (`BuildTreeWindow`, `TreeOpen`, `PixelWindows` 15) to the right of the Skills window that stretches to the right screen edge and is as tall as the Skills window: nodes by depth x row with connector lines (`RefreshTree`), points label, node text and an Unlock button; it closes with the Skills window. **The perk list is collapsible: one header button per level ('+ Level 2  COMING SOON'), the text under it when open (`perkOpen`, `perkHeads/perkBodies`, scroll view).** **A skill's description / replaces / spawns / XP-from text is a tooltip** on an orange '!' box at the top left of its card (`CreateInfoBox`, `PackTip`, `UpdateTip`). **Not built yet:** real effects for perks / nodes, more packs, the XP bar on the main screen, a cycle-skill key, a Stats / Log summary, a HowToPlay paragraph (see Todo.txt).


**Perk guests (Woodcutting level 5):** `Perk.guestType` works like `TreeNode.guestType`: from that level the block is listed in the Toggles window (`UnlockedGuests` / `GuestUnlocked` also read perks) and can be switched on to spawn in every rotation (off until the player ticks it). Woodcutting level 5 = Wood ("Lumber stock"), added to saved packs by the Woodcutting perk migration.


**Offline Progression is passive (2026-10-16):** it is never the skill in training (OfflineMode is always false, the Train button reads 'Earns while away', no pixel-pack buttons); its only XP is PixelOfflineProgress.Grant's offline clicks x offlineXpPerClick (0.25) via PixelSkills.AddOfflineXp, listed in the Welcome back window. An old save's 'offline chosen' switch is ignored.
