## PixelPauseMenu.cs (Settings screen)

The Settings screen is a scrolling list with section headers (**Gameplay, Interface, Accessibility, Display, Audio, Controls** - the Saving section was folded into Gameplay). Row helpers: `AddSettingToggle` (re-reads its value whenever the screen opens via `settingsRefreshers`), `AddSliderRow` (0..1, or a min / max / whole-number range with a value read-out and a reread getter, e.g. Display > 'Orbit field of view' = PixelOrbitCamera.FieldOfView), `AddDropdownRow` (every multi-choice setting is a drop-down now; the old cycle-button `AddChoiceRow` was deleted), `AddLookRow` (floor / sky picker = the shared `PixelUIKit.CreateLookDropdown` with big rows; the floor's row also holds its on/off tick box), `AddEyedropperButton` + `AddCycleButton` (small buttons beside a colour tick box), `AddWideButtonRow`, `AddHeaderRow`. `SettingsCatalog()` lists every BUILT row (section, label, kind, drop-down choices, current value, look source) for the Game Database's Settings tab, so a new row shows up there with no extra wiring.
**Current layout:** Gameplay = replay tutorial, abbreviate numbers, hide purchased, run in background, pause stops game, day / night cycle + length of a day, autosave message + autosave interval, floor (style + tick box), when the floor is off, sky. Interface = tips, event log, popups, block tips, next-up window, drop guide, fancy pause menu, pixel-assemble buttons, camera intro, menu buttons, neon bar glow (+ eyedropper + a small rainbow 'cycle colour' button), custom UI colour (+ eyedropper), custom bar colour (+ eyedropper). Accessibility = cube rotation, pulsing, colour-blind marks, popup size, event log size, UI scale, reset achievement popup position (last). Display = screen filter + strength, VSync, fullscreen, resolution. Audio = mute, UI click sounds (`PixelAudio.UiClicks`, gates sound id ui_click), the three volumes. Removed: Click effects (row only), Flat view (the View window has Orthographic), Fancy buttons / Fancy windows (always on now), Auto-contrast outline and Cube spotlight (PixelContrast.cs deleted). **Accessibility section** (collapsible header after Interface): cube rotation (switching it off restores the cube's scene pose, `PixelClicker.startRotation`), pulsing, colour-blind marks, click effects level, popup size, event log size, UI scale. Interface: first-time tips (`PixelHints.TipsEnabled`) + Replay tutorial (`PixelHints.ReplayTutorial`), event log on/off + text size (`PixelHints.EventLogEnabled/LogSizeChoice`), number popups on/off + size (`PixelUI.PopupsEnabled/PopupSizeChoice`), UI scale, colour-blind marks. Saving: autosave interval + message (`PixelSaveGame.AutoSaveChoice/AutoSaveMessageChoice`). **Menu search** (top right of the main screen, 'Paused' is left-aligned: `menuSearchField`, `OnMenuSearchChanged`): hides the button grid and lists matching menu entries plus up to 6 matching settings rows (`settingsItems` labels); a settings result calls `OpenFilteredSettings` (`settingsFilter`: `LayoutSettings` then shows only matching rows and their headings, folded or not); the search clears each time the menu opens. A Key Bindings screen (`BuildKeysPanel`, click a key, press the new one, Escape cancels) opens from Controls. **Row widths:** every row under a section header (toggles, choice rows, sliders, wide buttons) is `SettingsRowInset` (112) narrower than the list, exactly the Replay tutorial button's width. **Per-save settings sync:** `PixelSettingsSync.Known_` lists each PlayerPrefs key with its TYPE (0 int, 1 float, 2 string) - a key registered with the wrong type is read as 0 and overwritten on load (that wiped the eyedropped glow colour, the hues and the skill pack); an entry stored with another kind than the key's is ignored.

## PixelPauseMenu How To Play (tabs)

The pause menu has one **Game Guide** button (between Settings and Give feedback; it was called How To Play) that opens a screen with three TABS: **Controls**, **How To Play** (the written guide) and **Database** (opens the game database window) - the tabs: **Controls** (`Controls.txt`, formerly the pause menu's Controls button) and **Game Guide** (`HowToPlay.txt`); each tab is its own `GuideScreen` panel and the tab buttons switch between the panels (`BuildGuideScreen(..., isControlsTab)`). **Settings ends with a 'Keybinds' header** with one 'Change keybinds' button that opens the key-binding screen (titled 'Keybinds').

## PixelPauseMenu Game Guide text tabs (Controls and How To Play are two panels; the third tab, Database, opens the database window)

Two more screens that show **`Assets/Resources/HowToPlay.txt`** and **`Assets/Resources/Controls.txt`** (the user edits these files; `GuideScreen`, `BuildGuideScreen`, `RefreshGuideScreen`, `FormatGuideText`). File format: lines starting `//` are hidden notes, `# Heading` = coloured heading, `Key | Action` = two columns, anything else is shown as written (TMP rich text allowed). **When a keybind or control changes, update `Controls.txt`; when a major system is added, update `HowToPlay.txt`.**

### Deleting a save slot
Hold the RIGHT mouse button on a slot that has a save in the Save / Load window (PixelPauseMenu.UpdateSlotDeleteHold, deleteSlotHoldSeconds 0 = 1.4 s, a red PixelHoldMeter ring on the pointer): when the ring is full PixelSaveGame.DeleteSlot removes the file, its screenshot / meta and the pending name. The hover box shows 'Hold right click to delete'. Works from the main menu's Save / Load window too. The autosave list is not affected.


**Look search (2026-10-16):** the Floor and Sky rows are found by the name of ANY of their looks (`lookRows`, `RowMatches`) in the Settings search, and the pause menu's search lists up to 8 matching floors / skies as results ('Floor: Grass', '(in use)' highlighted) that switch to that look at once.

**Title plate (2026-10-18):** every section screen built with `BuildSectionPanel` (Settings, Stats, Save / Load, Guide, Quit, Restart, Key bindings, Playlist, Changelog) has a sunken rounded title plate across its top (`titlePlateColor`, StyleBox inset) with a thin accent line in the theme's Selected colour; the X (`AddCloseX`) sits inside its right end with equal gaps (PlatePad), a three-pixel ornament mirrors it on the left, and the title is centred between them (auto-shrinks if long). Geometry: PlateMargin / PlatePad / PlateHeight (titleFontSize x 1.45). The MAIN pause panel has the same plate (BuildTitlePlate): 'Paused' on the left after the ornament, the menu search box in its right end (where the X sits elsewhere), the sliding title line just under it. Small cubes with light trails fall from behind every plate now and then (PixelMenuFx.AddCubeFall, fancy menu only).
